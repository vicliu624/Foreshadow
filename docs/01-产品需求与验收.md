# 产品需求与验收

[English](01-product-requirements-and-acceptance.md) · 简体中文

Foreshadow 是跨平台信号研究工作台。本基线替代最初仅面向 uConsole / LoRa 的范围；带日期的报告保留各阶段实际实现与验证结论。

## 产品目标

1. 通过运行时接收机提供者采集有效宽带窗口，分别展示请求、兼容性和实际设置。
2. 展示频谱、瀑布、候选事件及运行计数，不阻塞采集。
3. 手动或通过支持的事件触发录制原始 I/Q，限制内存/磁盘，并软件重放。
4. 打开录制或冻结实时输入，检查样本、提取信道、测量窗口、比较模型并运行条件恢复。
5. 从结论、字节、帧或复数测量追溯源依赖，保留假设、失败、未知值和校验状态。
6. 保存重开配置、导出证据并复现处理过程。
7. 支持中英文资源、持久化停靠工作区、受控工具箱和安全更新激活。

## 结果解释

候选不等于设备身份或命名应用协议，结构匹配不等于 CRC 验证载荷。参考是生成数据，残差不自动成为 EVM；EVM 不证明应用校验或误码率，PHY 与应用校验分别表达。

功率使用声明数字单位，不冒充校准 dBm。样本时间、主机观察、保存和重放进度分开。缺口、未知硬件丢样、低幅度无效相位及不支持结果保持明确，不编造数据。

支持持续运行至停止，但尚未证明通用 24 小时实时无损或硬件无丢样。当前接收窗口内同时观察，调谐产生空档。自动 I/Q 事件保存目前由 LoRa 结构触发，不是所有检测器。

## 完成口径

实现、自动契约、原生界面、实际包、部署和正式发布分别记录。验收须包含环境、源码身份、输入来源、步骤/命令、结果和限制；历史包通过不自动覆盖最新分支。
