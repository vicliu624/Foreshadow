# 实施状态与风险决策

[English](05-implementation-and-risks.md) · 简体中文

本页是当前维护基线，不再沿用原始日历计划。早期 M0–M6 和 LoRa 单一范围由当前需求取代，历史实测证据继续保留。

## 已交付实现

- 运行时接收机、提供者整套配置/回读、宽带多速率及通用检测/事件。
- 独立 0.2.12 基础包及 SDRplay 服务客户端工具箱、独立安装的 SoapyRemote 服务、带连接设置的接收请求协议 2，以及 Windows/Linux r4 真实包与硬件验收。见[服务报告](reports/2026-11-14-receiver-service-review.zh-CN.md)。
- 第一方程序／插件 GPL-3.0-or-later，各包原始声明、对应源码、构建及替换材料，归档复查和原生许可证视图。
- 受管工具箱、签名目录、更新激活/回滚、持久化工作区和双语资源。
- 独立 FM 及 DTMB 原生节目流/媒体流水线。
- 波形实验室 P0–P3：窗口/时钟、联动原始视图、有界捕获/冻结、信道、窗口分析、模型、恢复证据、定位和保存重开。
- 有界 FSK、LoRa PHY、显式成对编码帧族；训练式 BPSK/QPSK、OFDM 同步、信道估计、均衡和数据 EVM。
- 各报告源码身份上的 Windows/Linux 真实评审包及 Intel Mac 验收/部署。

Foreshadow 改名与文档属于维护，不自动构成新的签名正式发布或全部硬件再验收。

## 仍需资格验证

| 风险/未知 | 所需证据或决策 |
|---|---|
| 24 小时实时无损/硬件连续性 | 每种速率/负载的持续实体输入及采集/录制/分析计数 |
| 弱/边缘/重叠检测 | 受控矩阵、反例、灵敏度/连续性，不能编造准确率 |
| 任意未知协议恢复 | 当前不承诺；新方法需所属协议/参数与独立真值 |
| 当地 DTMB 节目实收 | 完整通带、天线到 TS 到播放正例，不能用 PN/codec 夹具替代 |
| 最新研究分支 Apple Silicon/其他 Mac | 相应原生构建、界面、包/运行库及硬件 |
| Foreshadow 正式发布 | 冻结源码、平台检查、真实包、目录评审和仓库外私钥签名发布 |
| 厂商 API 与嵌入式固件 | 基础包／客户端没有厂商 API／驱动，用户安装的服务软件保留其条款；未授予新的厂商再分发或独立固件授权 |
| 完整基础包的电视编解码专利 | [实际免费开源分发评估](codec-patent-assessment.zh-CN.md)、具体有效权利要求／地域及兼容授权或不适用依据；与客户端、API、固件分别判断 |

## 变更策略

修改前识别变化轴、所有者、消费者和组装；保留标识/数据及冻结历史别名。新结果/生命周期明确升级，不在稳定界面、会话、导出、安装器增加实现 ID 路由。适用时补独立提供者与资源增量。

日常 CI 使用可信自托管 Runner，托管矩阵仅显式正式发布验证。私钥和私人 RF 数据不入库。

参见[需求](01-产品需求与验收.md)、[测试](04-算法与测试方案.md)、[完成审计](reports/2026-11-12-波形实验室完成条件审计.md)、[PSK/OFDM](reports/2026-11-12-PSK与OFDM接收验收.md)及 [Mac](reports/2026-11-12-macOS原生部署与接收流程验收.md)。报告结论以各自日期和源码身份为准。
