# 构建与命令行操作

[English](07-building-and-cli.md) · 简体中文

本页是当前指南。过去 LoRa 整数采样率限制、固定 1 MHz 推荐及“无桌面入口”属于历史，不再作为现状。产品入口见 [README](../README.zh-CN.md)，目标与所有权见[源码地图](../src/README.zh-CN.md)。

## 依赖

需要 CMake 3.20+、C++20、Threads、OpenSSL Crypto 3.0+、libarchive。nlohmann/json 3.12.0 与 KissFFT 131.1.0 固定归档哈希，FFTW/VOLK 为可选加速。缺少驱动应明确不可用，不能模拟设备。

桌面要求 Qt Widgets、Network、LinguistTools（非 Mac 6.2+，Mac 6.8+）；Multimedia 用于音频，SerialPort 用于 Pager 主机工具。厂商库属于接收机。完整电视从固定源码组装，x86 需要 shell/Make/NASM，见[原生依赖](../third_party/README.zh-CN.md)。

完整平台配方见[发布工作流](../.github/workflows/release.yml)，日常使用[自托管工作流](../.github/workflows/desktop.yml)，不能改为托管日常构建。

## 构建与安装

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DSIGNALSCOPE_REQUIRE_GUI=ON -DSIGNALSCOPE_REQUIRE_AUDIO=ON
cmake --build build --parallel 4
ctest --test-dir build --output-on-failure
cmake --install build --component SignalScope --prefix "$PWD/stage"
```

Visual Studio 使用 `-G "Visual Studio 17 2022" -A x64`、匹配 Qt MSVC 和依赖工具链；构建/安装加 `--config Release`，CTest 加 `-C Release`。README 提供示例，Qt 前缀不自动供应其他依赖。

Mac 显式选择编译器/运行库和部署下限。已验收 Intel 为 LLVM 21.1.8、Qt 6.8.3、macOS 14.3.1 / target 14.0。通过 `AMC_MACOS_EXTRA_RUNTIME_LIBRARIES`、`AMC_MACOS_EXTRA_RUNTIME_LICENSE_FILES` 声明非系统闭包和通知，不依赖开发 Homebrew 路径，见[规格 26](26-macOS原生构建与部署验收规格.md)。

`SIGNALSCOPE_GUI=OFF` 省略桌面，`SIGNALSCOPE_TELEVISION=OFF` 显式省略电视。`SIGNALSCOPE_REQUIRE_GUI/AUDIO/RTLSDR/SDRPLAY` 分别要求对应依赖，避免静默缺项。`SIGNALSCOPE_FFMPEG_ROOT` 是开发覆盖，不代表 codec 等价。`SIGNALSCOPE_LEGACY_TESTS=ON` 启用保留 Python 测试，生产 DSP 为原生。

离线可通过 `FETCHCONTENT_SOURCE_DIR_JSON`、`FETCHCONTENT_SOURCE_DIR_KISSFFT` 和相应固定原生依赖覆盖提供已核对来源，保留哈希，不能因库/codec 同名而降级。

## 安装验证

Windows/Linux 入口 `stage/bin/signalscope-gui[.exe]`，Mac 为 `stage/Foreshadow.app`，CLI 位于 `Contents/MacOS`。安装组件 `SignalScope` 和命令名保留兼容。`ResearchExamples` 单独安装实际包检查使用的外部研究载荷。

```sh
cmake --install build --component ResearchExamples --prefix "$PWD/stage"
cmake -DAMC_CLI="$PWD/stage/bin/signalscope" -P tests/check_packaged_receivers.cmake
cmake -DAMC_STAGE="$PWD/stage" -DAMC_TEST_BIN="$PWD/build" -P tests/check_desktop_package.cmake
python tools/docs/check_docs.py
```

按 Windows 多配置或 Mac 路径调整。真实归档需解到中文/非 BMP 路径，检查模块、资源、运行库、通知、独立工具箱、启动和布局重启。`tools/distribution/package_release.py` 从已测安装树生成主体/接收机/研究包及未签名目录；签名发布属于仓库外私钥操作。

## 命令面

准确能力见实际 `signalscope --help` / `--build-info`。

| 领域 | 命令 |
|---|---|
| 接收机 | `receiver-plugins`、`devices`、`probe`、`parameters`、`recommend`、`validate`、`configure` |
| 数据 | `synth`、`capture`、`inspect`、`export`、`replay` |
| 检测 | `detect`、`scan`、`monitor`、`replay-events` |
| 存储 | `store-snapshot`、受配额约束的 `monitor` |
| 音频 | `fm-audio` |
| 分发 | `signalscope-toolboxes check|list|install ID|enable ID|disable ID|uninstall ID|rollback ID` |

接收机命令支持 `--receiver ID`、索引及提供者支持的序列号/天线；厂商设置通过 `--settings JSON`。`probe` 返回能力，`parameters` 描述控件，`validate` 返回硬件/分析问题，无效组合非零退出。`configure` 应用、必要时确认启动、回读，不保存 I/Q；关闭后未必保留硬件状态，采集会重新配置。

CLI 频率 Hz，GUI `--frequency` MHz。线程 1–32，推荐与覆盖取决于主机和提供者。输出必须全新，父目录可写；不支持的增益、速率、编码报错。Ctrl+C 正常取消，错误保留部分/失败状态。

```sh
signalscope devices --receiver rtlsdr
signalscope probe --receiver sdrplay
signalscope validate --receiver sdrplay --purpose capture --rate 10000000
signalscope configure --receiver sdrplay --rate 6000000 --gain auto --antenna 'Antenna B'
signalscope synth --output tone-demo --rate 2000000 --seconds 0.1 --tone 25000
signalscope inspect --input tone-demo/capture.sigmf-meta
signalscope replay --input tone-demo/capture.sigmf-meta --speed 0
signalscope scan --input capture-001/capture.sigmf-meta --modulations all
signalscope detect --input capture-001/capture.sigmf-meta --bw 125000 --sf-min 7 --sf-max 12 --search-width 1000000
signalscope replay --input capture-001/capture.sigmf-meta --start 1 --duration 0.5 --speed 0 --output slice-001
signalscope monitor --input capture-001/capture.sigmf-meta --output replay-events --seconds 0
```

`replay --speed 1` 原速、`0` 最快；monitor 文件输入有自己的节奏。软件重放不发送。切片保留父偏移，不产生新的 RF 时间。`scan` 输出含源位置的 JSON 行，候选不是载荷解码。

## 桌面与诊断

```sh
signalscope-gui --language en --settings-dir review-profile --output review-events
signalscope-gui --replay capture-001/capture.sigmf-meta
```

`--settings-dir` 隔离偏好，未覆盖分发根时也隔离工具箱。普通设置/数据保留 SignalScope 根。语言可选 system 或已安装标签；模块参数在所属面板。

构建测试后运行 `waveform_recovery_workflow_test --export-review-fixtures NEW_DIR` 生成并重开六用例。实体验收通过 `SIGNALSCOPE_HARDWARE_ACCEPTANCE=ON` 单独构建并手动执行；普通 CTest 不开硬件。

缓冲/存储见[长期监听](08-长期监听与事件存储.md)。软件计数、ADC 位数、配置接受和文件大小不证明校准质量或硬件无丢样。项目许可仍需明确决定，依赖通知及源码/重链接材料必须保留。

## 独立接收机服务（0.2.12）

基础应用与可选 SDRplay 服务客户端工具箱分别交付，厂商 API/驱动仅由独立安装的接收机服务加载。
提供者所有的连接描述和请求协议 2 在设备枚举前传递地址，界面、会话和 CLI 保持通用。
固定 BSL SoapyRemote 客户端依赖 SoapySDR 0.8.1，支持离线覆盖
`FETCHCONTENT_SOURCE_DIR_SOAPYREMOTE`。只有声明为随主体捆绑的提供者进入基础归档；
原始 CMake 安装目录是组装暂存树，不是已验收基础归档。SDRconnect 评估、安装、协议、连续性和
许可边界见[接收机服务](receiver-services.zh-CN.md)。
