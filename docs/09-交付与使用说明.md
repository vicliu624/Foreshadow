# 交付与使用说明

[English](09-delivery-and-user-guide.md) · 简体中文

平台安装/构建及完整截图见 [README](../README.zh-CN.md)。本页说明实际操作顺序；旧 Actions 资产 ID 与私人构建路径不再作为当前安装入口，正式下载使用 Releases，历史结论查看报告总览。

## 选择输入

- **实时接收机：** 需要已安装的提供者及实体设备或接收服务。本地硬件驱动位于拥有设备的电脑，先在接收机设置校验并应用。
- **I/Q 录制：** 打开 SigMF 元数据并保留数据文件，以录制时钟/编码为准。
- **已保存分析：** 实验室“打开分析”恢复已应用处理，从验证后的源重新计算。
- **节目流：** 电视面板打开 TS，只验证传输/媒体，不代表 RF 同步。

无格式、速率和来源描述的二进制不能猜测。容器支持由来源提供者决定；离线无需接收机。

## 连接独立 SDRplay 服务

自 0.2.12 起基础包和 SDRplay 客户端分别交付。安装 **SDRplay Support**，打开 **Receiver settings → SDRplay**，填写 **Receiver service** 后 **Refresh devices**。选择设备、天线、速率、增益及高级设置，应用完整配置并查看实际回读后再开始。新安装需要配置一次服务地址；已配置的工作站会随接收机设置保存地址，并在重启后继续使用。

接收机电脑独立运行 SoapySDRServer 和用户安装的厂商 API／驱动，Foreshadow 不加载这些本地硬件组件。同一硬件启动第二客户端前先停止当前使用者。服务安装、可信网络条件及 SDRconnect 对照见[接收机服务](receiver-services.zh-CN.md)，实际包／硬件证据见 [r4 报告](reports/2026-11-14-receiver-service-review.zh-CN.md)。

## 工作区

选择 **View → Layout → Waveform research layout**。波形实验室与“测量与研究”分别是面板，View 找回已关闭面板。停靠/浮动/标签持久保存；只有明确选择预设才重排，缩放不重应用。

窄屏使用标签与滚动参数/复数页。关闭/隐藏不必然停止任务，使用捕获、音频或监听自身停止入口；断开释放全部接收使用者。

## 原始观测与坐标

打开来源，适用时输入文件起点/样本数并载入。概览提供上下文，细节可到单样本。点击/拖动设置 B，Shift 点击设置 A，右拖选区，滚轮或 +/− 缩放，Home 恢复已载入范围。

查看 I/Q、幅度、包裹/展开相位和瞬时频率。检查器显示原始/文件坐标、值、有效性与 A/B 差。大整数源位置不丢精度；缺口重新展开/平滑，低幅度相位/频率无效。“可计算”不证明载波或足够 SNR。

## 捕获与冻结

在捕获页请求满足提供者需求的采集，检查请求/实际值及启动校准/ADC 信息。开始有界捕获，观察接受/拒收和保留淘汰，冻结有用区间；其他实时任务可继续。恢复或重新捕获明确执行，源/会话变化不沿用旧结果。

启动事实仅覆盖首样本前，不证明冻结区间持续校准或无 ADC 过载。未知经保存重开仍保持未知。

## 目标信道与窗口

选时频区间，在目标信道配置频移、低通、重采样并应用。检查带宽、滤波延迟/支撑、有理映射和无效边缘，原始/处理后对照。处理点可依赖多个源样本。

窗口研究提供 STFT、PSD、自相关、频率直方图和统计；选原始/处理输入，设置窗/长度/hop 后应用。功率为声明数字单位，不补零制造有效谱；绘图聚合不改测量。

## 模型

在模型对照启用、选输入/注册模型、编辑提供者参数及对齐/拟合后应用，当前输入视区成为应用区间。观察叠加、残差和复平面，生成参考明确标注。

草稿不改已完成结果；缩放不重拟合或改变时间原点。错误/取消保留上次结果，换源/处理改变使不兼容结果失效。保存只取已应用参数。残差不是 EVM 或身份。

## 恢复

在证据与恢复启用，选择原始/处理输入、提供者、完整波形/成帧参数后应用。结果可包括 Hex/ASCII、帧与校验、符号/比特/值、阶段/事件及复数测量。

- 解释前核对候选/已验证/修复/截断。
- `??` 为未知，不能伪造二进制。
- CRC 未携带、不适用、失败、未知及通过分开。
- 点击/双击或“定位输入”返回支撑区间，原始/处理依赖明确。
- JSON 导出完整结构；字节仅导出允许的已知值，候选性质仍保留。

有界 FSK 需要符号栅格/频率/成帧，LoRa PHY 需要声明射频参数，成对帧族额外需要经验编码/校验配置；不是通用应用解码器，不推断设备归属。

## PSK/OFDM 评审

1. 生成或打开原生合成评审用例 05 QPSK / 06 OFDM。
2. 打开分析，检查来源、提供者及应用参数。
3. 核对锁定、频偏、有效/排除点及 EVM 参考来源。
4. 星座/信道页选择平面/组；点是观测，叉是生成参考。
5. 检查信道与源依赖，点击测量点返回波形；紧凑布局滚动查看。
6. 另存、重开、导出证据及已知字节，核对源身份与方法。

数据参考仅测量，不训练同步/均衡。错误训练、深衰落、缺口、有效点不足或排除过多不能发布可信 EVM，见[精确条件](25-PSK与OFDM接收及EVM规格.md)。

## 监听、录制、事件

选择检测器、配置、开始，分别检查队列/丢弃和事件证据。手动及 LoRa 触发保留 I/Q，重要录制导出到配额外。打开录制软件重放、暂停/继续、导出切片；重放时间不是原始 RF 时间。未知事件仍显示描述/特征，不隐藏或强归类。

## FM、电视、工具箱

View 打开 FM/DTMB，可独立请求租约，无需先监听。填写频率/输出后启动；冲突保留已有使用者并解释。电视支持实时/录制 I/Q 或 TS，有效表恢复后才列节目/音轨；停止任务而非只藏面板。

插件 → 工具箱中心显示可信包、依赖、版本和重启。冲突任务期间拒绝安装/更新/启停/卸载。离线导入仍认证目录；主体激活确认启动并失败回滚，断网不禁离线研究。

## 故障排查

| 表现 | 检查 |
|---|---|
| 无设备 | `receiver-plugins`、提供者诊断、设备／序列号；服务连接还需检查已保存地址／服务端及接收机电脑的驱动／API／USB 权限 |
| 服务连接但没有样本 | 硬件占用、服务日志、协商的流／状态端口与网络可达性；只转发控制端口 55132 不够 |
| 不能应用 | 整套参数/联动、端口/频率/采样及所选分析兼容性 |
| 无事件 | 实际带宽/IF、检测器、连续性/负载和门槛；不能据此证明无 RF |
| 录制不完整 | 源缺口、预录保留、分析滞后、截断/尾部标志和写盘错误 |
| 模型/恢复失败 | 来源/范围/时钟、完整已应用配置、训练/参考覆盖、连续性和预算 |
| 无 EVM | 锁定、参考来源、至少 8 点、排除不超过 20% |
| 分析无法重开 | 源双文件、身份、提供者/版本和相对路径 |
| 面板消失 | View 或明确恢复默认，不先删除偏好 |
| 更新失败 | 网络/代理、可信目录/平台、可写根、任务冲突和助手诊断 |

见[验收总览](README.zh-CN.md)、[存储](08-长期监听与事件存储.md)、[架构约束](16-扩展边界与开闭原则规格.md)。报告准确构建身份、步骤和诊断，公开报告不带凭据/私人录制。
