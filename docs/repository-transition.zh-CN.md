# Foreshadow 仓库迁移说明

[English](repository-transition.md) · 简体中文

维护者要求以 `vicliu624/Foreshadow` 创建独立 Git 历史的新源码仓库，替代 `vicliu624/AMC`。
初始源码来自原 Foreshadow 分支 `b4d672727536a94e52d3697b1440e251a0037803`，
并更新当前仓库／下载地址。初次发布还为波形视图补充显式 `QLocale` 头文件，以兼容
自托管 Linux Runner 的 Qt 版本；另设独立 CI 构建目录，并移除误入源码的 Qt 安装日志。
本地化测量测试先归一化区域符号再验证数值回读，因为 Runner 的 Qt 无法解析其自身输出的
阿拉伯语科学计数法；应用显示格式保持原样。
本轮先公开源码，二进制另行发布，不随本轮上传。

保留原始第三方版权声明、许可证、第一方 GPL 授权和源码来源。新 Git 历史不改变许可义务，
也不产生新的编解码专利、厂商 API 或固件授权。完整功能保留。兼容命令、包 ID、设置根、
格式及信任公钥维持原身份，当前目录地址和官方资产地址白名单改用新仓库；后续合格二进制
发布前不宣称已有签名目录可用。

原共享 Git 元数据、全部本地引用／工作树、远端镜像、仓库讨论／元数据及已发布资产，均在
新仓库之外归档。忽略的构建产物、私人录制、凭据及备份 Git 数据库不导入新历史。
旧工作目录在移出旧 Git 元数据后保留为本地源码快照。

有日期报告保留原源码哈希、文件名及测量结果。旧 AMC Actions／提交／发布链接属于历史证据，
退役后可能不可访问；不会改写为新历史的测试结果，维护者保留本地证据归档。
从新仓库发布二进制之前，应重跑适用构建、架构、契约及发布包验收。
