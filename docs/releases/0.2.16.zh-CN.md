# Foreshadow 0.2.16

[English](0.2.16.md) · 简体中文

本补丁修复调查接收机工作站整夜运行后 `Too many open files` 报告时发现的资源生命周期
缺陷。[原生审核报告](../reports/2026-11-25-resource-lifetime.zh-CN.md)记录可复现的问题、
修复前后的描述符数量及现场归因限制。

## 修正内容

- SDRplay 远程客户端恢复日志连接前，回收旧线程并关闭旧套接字；取消订阅不再新开
  替代连接，跨线程完成标志改为原子变量。
- 远端设备创建被拒绝时，异常展开会释放日志订阅；整个构造成功后才转交所有权。
- 录制目录锁描述符不再由子进程继承：POSIX 使用 `O_CLOEXEC`，Windows 使用
  `_O_NOINHERIT`。

修改集中在录制后端与接收机客户端组装，既有会话、界面、安装器、包 ID、命令名和设置
保持兼容。ADS-B、WSPR、波形／PSK／OFDM、电视和可选工具箱的完整功能保留；独立接收机
服务及厂商 API 不随包分发，也不由本补丁修改。

## 验证与发布范围

新增测试统计设备创建失败／成功、日志反复断线恢复、录制／回放结束与取消，以及提供者
采集成功／失败时的原生进程资源数量。客户端进程在多轮操作中持续复用，避免进程退出
掩盖资源残留。独立上游服务与 TCP 故障中继验证真实客户端，录制覆盖 CU8 和 CI16。
Windows 除子进程行为外，还直接检查锁句柄继承标志；就绪检查在截止时间内等待完整
行并兼容原生行尾，不把第一次进程通知等同于已经就绪。

本次范围为 **Windows x64、Debian 13 x64 和 Debian 13 ARM64／uConsole**。发布前 Linux
审核通过 130 项测试，另有两项因无音频设备跳过；公开发布之前，冻结的 0.2.16 源码必须
完成正式构建、实际归档、材料及原生运行检查。各平台最终计数和源码身份以发布资产中的
`release-qualification.json` 为准。macOS 不在本次范围内；短时软件检查不构成实体接收机
整夜运行或无限期无损的验收。

## 更新方式

进入 **Plugins → Toolbox Center → Check for updates**，安装应用及相应接收机／研究
工具箱，再重启。**需要同时更新 SDRplay Support 和主程序**：日志连接修复位于独立
客户端包。设置、录音与已保存分析保留；工作站当前网络路径依赖的 Windows 转发需要保持在线。

保留上游原始源码归档及 BSL-1.0 声明；本地客户端修改、构建配方、双语说明及哈希随相应
包提供。源码修改在当前构建目录的私有副本中进行，固定上下文改变时配置失败。主程序与
自研插件继续采用 GPL-3.0-or-later，签名只在发布电脑上执行，私钥不进入仓库、构建或部署主机。
