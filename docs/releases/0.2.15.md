# Foreshadow 0.2.15

English · [简体中文](0.2.15.zh-CN.md)

This patch follows [0.2.14](0.2.14.md). The 0.2.14 application and three independent toolboxes were published and upgraded through the receiver workstation's normal signed Toolbox Center. Restart, cold launch, settings and twelve existing data files were preserved. Physical capture, replay, exact export and the updated Power Report passed. The subsequent ADS-B RF check exposed sustained processing overload; 0.2.14 remains immutable and this patch is prepared as a separate release.

## ADS-B processing correction

The ADS-B provider previously recalculated the same fractional integration boundaries inside every sample/phase probe, including five identical phase plans at 2 MS/s. Integration plans are now calculated once per sample rate and duplicate plans are evaluated once. PPM decisions, CRC checks, source timestamps, discontinuity resets, supported rate declarations and the eight-MiB live queue budget retain their existing semantics. Stable host consumers and receiver protocols do not change.

The independently generated noisy CI16 input probe now runs for **60 wall-clock seconds at 2 MS/s** as a registered regression, requiring all 120,000,000 pairs and 6,000 known frames, zero software rejection and zero discontinuities. A standalone optimized native run on the receiver workstation passed with an 80,000-byte queue high-water mark. The previous constant-floor 30-second probe remains separate historical evidence; it did not represent random RF background. These are bounded software observations, not a hardware-wide or indefinite losslessness guarantee.

## Retained functionality and release checks

All 0.2.14 changes remain: offline country/province boundaries, named cities, selected-region highlighting, a geographic card, an Area column, zoom and scale; recorder provenance, custom Linux desktop launch preservation and consistent toolbox selection. Province containment and nearby-city distance are distinct. Full television/media and independent receiver/research toolboxes remain included, with their corresponding source, dependency source, notices and replacement instructions.

Release selection remains **Windows x64, Debian 13 x64 and Debian 13 ARM64 / uConsole**. Frozen-source formal builds and extracted archives must pass before publication. Native runtime qualification and an actual public-catalog update on `.42` are recorded separately after publication; this frozen preparation note does not claim those future checks already passed. macOS is outside this selection. Signing remains local to the publisher; hosted formal staging only transfers hash-approved files or reconstructs hash-pinned dependency source without signing keys.

Update through **Plugins → Toolbox Center → Check for updates**, install the application and relevant independent toolbox updates, then restart. The accepted Windows forwarding connection used by `.42` must remain online. Existing package IDs, command names, settings roots and file formats remain compatibility protocols.
