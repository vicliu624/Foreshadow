# Foreshadow 0.2.15

[English](0.2.15.md) · 简体中文

本补丁接续 [0.2.14](0.2.14.zh-CN.md)。0.2.14 主程序和三个独立工具箱已公开发布，并经接收机工作站的正常签名工具箱流程升级。重启、冷启动、配置和十二份旧数据均保留，实采、回放、逐字节导出及新版 Power Report 已通过；随后 ADS-B 射频复验发现持续处理过载。0.2.14 保持不可变，本补丁独立准备发布。

## ADS-B 处理修复

原 ADS-B 提供者在每个输入样本、每次相位探测中重复计算积分边界，2 MS/s 时甚至重复执行五套完全相同的相位方案。现在按采样率预计算积分方案，相同方案仅执行一次。PPM 判决、CRC 校验、源时间戳、断点重置、采样率声明和八 MiB 实时队列预算保持原有语义，宿主稳定消费者与接收机协议没有变化。

独立生成的带噪 CI16 输入验证现作为正式回归，按 **2 MS/s 持续输入 60 秒墙钟时间**，要求处理全部 120,000,000 对采样、恢复 6,000 个已知帧、软件拒收及连续性中断均为零。接收机工作站上的独立原生优化构建已通过，队列峰值为 80,000 字节。此前常量底噪的三十秒探针单独保留为历史证据，不能代表随机射频背景。这些有限的软件观测不构成硬件或任意时长无丢样保证。

## 保留功能与发布检查

本次同时整合 `2ec2c1322338a5b7ccc0b9c5c5f2b64bbc409ae2` 的 WSPR：提供者维护的实时与录音解码、原生英文面板、有界采集／搜索工作线程、源坐标、断点分段和明确的未解析呼号哈希。纳入独立 WSJT-X 参考、弱信号、编解码、取消、录音及本地化面板契约，并注册 140 秒、2 MS/s 参考输入回归，覆盖完整高采样率路径及分离的队列预算；最终各平台结果须来自冻结发布构建。实现不含 WSPR-15 和自动 WSPRnet 上传。所用 WSJT-X Fano 源码、原通知、GPL 和固定来源均进入三个平台许可配置。

保留全部 0.2.14 变更：离线国家／省级边界、城市名、选中行政区高亮、地理位置卡片、Area 列、缩放和比例尺，以及录制来源、自定义 Linux 桌面启动参数保留和一致的工具箱选行行为。省级归属与附近城市距离分别呈现。电视／媒体和独立接收机／研究工具箱完整保留，附带对应源码、依赖源码、通知与替换说明。

发布平台仍为 **Windows x64、Debian 13 x64、Debian 13 ARM64／uConsole**。正式公开前须完成冻结源码构建和实际解压包验收；本机运行及公开后 `.42` 正常更新另行留证，本文冻结准备说明不提前声称未来检查已通过。本次不含 macOS。签名仍在发布者本机进行；托管正式发布环境仅转存哈希已批准文件，或依据固定哈希重新收集依赖源码，不接触签名私钥。

通过 **Plugins → Toolbox Center → Check for updates** 安装主程序及相关独立工具箱更新，随后重启。`.42` 已接受的 Windows 转发连接需保持在线。包 ID、命令名、配置目录与文件格式保留为兼容协议。
