# Foreshadow 0.2.14

[English](0.2.14.md) · 简体中文

本维护版本包含 [PR #2](https://github.com/vicliu624/Foreshadow/pull/2)，已通过 `7ab14d9` 合并至 `main`。本次发布平台为 Windows x64、Debian 13 x64 和 Debian 13 ARM64／uConsole，不包含 macOS。正式发布须完成下述冻结源码原生构建、解压包检查、对应源码校验及本机目录签名；准备完成不等于已经发布。

## 变更

- ADS-B 新增离线国家／省级边界、城市地名、选中行政区高亮、地理位置卡片、行政区列、缩放按钮和比例尺。行政区包含关系与附近城市距离分别说明，并补齐 Natural Earth 数据来源、对应源码和资源预算契约。
- 新 SigMF 录制标注 Foreshadow 及实际构建版本；历史元数据继续可读，完整导出保留源字节。
- 对同一安装具有有效受控启动器的 Linux 桌面入口，更新保留已有自定义启动选项。
- GUI／CLI 冷启动通过可选绝对 UTF-8 `distribution_root` 保持所属工具箱目录，继续兼容旧启动器配置。
- 工具箱操作依据实际选中行，包括未改变键盘当前单元格的无障碍选行。
- 实机波形验收识别明确的接收机重配置过渡，其他错误、资源预算和冻结观测身份检查保持严格。

[RSPdx-R2 流程报告](../reports/2026-11-24-rspdx-r2-workflow-review.zh-CN.md)记录推动本轮修复的真实采集、录制、回放、波形研究和签名工具箱生命周期证据。报告中的本机评审源码及计数属于历史证据，与本版本最终产物及验收记录分别说明。

## 发布检查

现有正式工作流使用匹配源码和已审核依赖材料构建三个平台，验证基础包及独立工具箱事务、原生 GUI／媒体／接收机流程、独立 AVS+／DRA 参考，以及含中文和非 BMP 字符的解压路径。音频设备跳过项及平台计时限制必须按实际情况报告。

主程序及每个独立接收机／研究包均包含匹配的对应源码、依赖源码、声明及替换说明。发布者在签名前依据仓库审核配置校验实际归档内容。既有信任公钥及目录地址保持不变，签名私钥不进入仓库、CI 或部署主机。

发布后，接收机工作站须通过 **Plugins → Toolbox Center → Check for updates** 发现 0.2.14，使用正常签名目录事务安装、重启并激活，同时保留独立 SDRplay 客户端、接收机配置、录制及已确认的 Windows 转发连接。这是发布后必做检查，本冻结源码说明不提前声称已完成。

## 兼容与范围

包 ID、设置根目录、CLI 名称及文件格式继续作为兼容协议。保留完整 FM、波形、ADS-B、DTMB 和电视／媒体功能。SDRplay Support 是独立网络客户端，不包含厂商 API／服务及固件。继续采用 GPL-3.0-or-later，并保留既有编解码评估及提供者声明。

此前实机报告记录了客户端读取超时及首次短时波形采集的输入拒收，分别说明主分析丢弃为零和后续独立租约验收的结果。该报告和软件／安装包检查均不构成硬件采样持续无损、校准 RF 功率、物理音频输出或未知空口信号解码成功的保证。`.42` 更新使用已明确确认的 Windows 转发连接，转发电脑须保持在线。
