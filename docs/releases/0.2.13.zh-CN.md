[正式构建](https://github.com/vicliu624/Foreshadow/actions/runs/45312368287)在三个平台使用同一冻结源码。
实际下载产物另完成原生运行复验，包括 AVS+/DRA、英文提供者创建及中文／非 BMP 路径。
生产源码归档也在 Debian 上以 `BUILD_TESTING=OFF` 成功编译及安装。

构建后仅修复发布验证工具（`0a0875a`），在 Windows 校验 POSIX 链接时避免把别名复制成
普通运行库。27 项发布契约及对应自托管 CI 通过；应用／运行时源码和已验收产物仍为冻结的
`b2eecf9`。这些更新不增加实体射频、长期硬件连续性、实体声音或 macOS 验收结论。

本版本增加内置 [1090 MHz ADS-B 模块](../adsb.zh-CN.md)：周期探测、连续 PPM/CRC 处理、
离线恢复证据以及航空器地图/列表工作区。接收要求、解码、有界队列、描述、翻译和
离线 Natural Earth 地图资源均由模块拥有。既有接收、恢复和桌面消费者保持通用协议。

ADS-B 实现在 ARM64 uConsole 的本地 0.2.12 构建中通过 14 项选定测试，包含架构及
既有恢复/实时研究回归。按节奏输入的 30 秒合成流恢复 3000/3000 帧，软件输入拒绝为零。
实际地图、语言回退、重启布局及 Unicode 路径检查通过。这些证据不代表 0.2.13 冻结源码
的平台验收，也不代表物理射频或硬件丢样验证。

本地 ADS-B 构建关闭了电视；公开更新必须保留完整既有功能，包括 DTMB 和固定媒体依赖。
物理 1090 MHz 采集没有得到有效帧，并记录了 PLL 警告。

## 发布门槛

- 冻结本版本源码，收集匹配的审核依赖材料。
- 通过既有发行工作流构建、测试每个发布平台，验证解包后的 Unicode 路径及应用/工具箱升级事务。
- 核对目标客户端编译的目录地址与信任密钥兼容性。
- 使用已有匹配密钥在本地签署验证后的目录；私钥不得进入 Git、CI 产物或远端机器。
- 同时发布更新包、对应源码和签名的 `catalog.json`。

更新应用 ID 保持 `org.amc.ams`；配置根、文件格式、包 ID 和接收器协议继续作为兼容标识。

## 平台与材料基线

本次审核的发布组合为 Windows x64（Qt 6.8.3 / OpenSSL 3.6.5），以及 Debian 13 x64、
Debian 13 ARM64（Qt 6.8.2 / OpenSSL 3.5.9 SDK）。Windows 使用已记录的 vcpkg 修订；
Debian 作业在构建前将实际安装的 SDK 源包身份与交付的 `.dsc` 文件逐项比较。
两个 Linux 架构分别验证原生构建、实际解包档案及包事务。uConsole 的 RPi 修改版 OpenSSL
运行时与通用 Debian 构建 SDK 分开记录，并使用实际 ARM64 发布资产验证兼容性。
macOS 不在本次发布组合内。

完整基础包保留 FM、波形实验室、DTMB 及固定电视／媒体依赖。
SDRplay 网络客户端和其他独立工具箱继续单独分发，不包含厂商 API／驱动或固件。
基础包携带 Natural Earth 地图来源及公有领域声明。
既有编解码评估继续适用；发布不产生新的专利授权，也不确立普遍的免费下载豁免。

## 旧 AMS 安装的一次性迁移

旧 AMS 客户端可能仍内置已经退役的 `vicliu624/AMC` 目录地址。
该仓库已删除，无法从中发现 `vicliu624/Foreshadow` 的发布。
请下载与你的平台匹配的完整合格便携档案，解压到新的应用目录，再启动其中的程序。
在确认新程序及所需接收机正常之前保留原安装；录制文件和用户配置继续放在应用目录之外，
现有配置根及包 ID 保持兼容。迁移无需用户提供签名私钥或厂商 API 文件。

新程序使用 Foreshadow 的目录地址及既有公钥。不要修改信任锚或接受未签名目录来绕过迁移。
