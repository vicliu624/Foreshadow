# Foreshadow 0.2.13 release candidate

English · [简体中文](0.2.13.zh-CN.md)

Status: prepared source, not yet published as an online update.

This version adds the bundled [1090 MHz ADS-B module](../adsb.md): periodic
detection, continuous PPM/CRC processing, offline recovery evidence and an
aircraft map/list workspace. The module owns reception requirements, decoding,
bounded queues, descriptions, translations and offline Natural Earth map assets.
Existing receiver, recovery and desktop consumers retain their generic protocols.

The ADS-B implementation was tested in the 0.2.12 local build on ARM64 uConsole;
14 selected tests passed, including architecture and existing recovery/live
research regressions. A paced 30-second synthetic stream recovered 3000/3000
frames without software input rejection. Native map, language fallback,
restart-layout and Unicode-path checks passed. These observations are not
0.2.13 frozen-source platform acceptance or physical RF/hardware-loss evidence.

The local ADS-B build excluded television; a public update must retain the
complete existing feature set, including DTMB and the pinned media dependency.
Physical 1090 MHz capture did not yield valid frames and reported a PLL warning.

## Publication gates

- Freeze this version's source and collect matching reviewed dependency materials.
- Build and test each published platform, extracted Unicode-path archives and
  application/toolbox upgrade transactions through the existing release workflow.
- Verify compatibility with the catalog URL and trust key compiled into target clients.
- Sign the verified catalog locally with the existing matching key; never put the
  private key into Git, CI artifacts or remote machines.
- Publish packages, corresponding source and signed `catalog.json` together.

The update application ID remains `org.amc.ams`; settings roots, file formats,
package IDs and receiver protocols remain compatibility identifiers.
