# Foreshadow 0.2.13

English · [简体中文](0.2.13.zh-CN.md)

The source candidate `2d90de2` and its provider-assembly boundary correction were
merged into `main` through [PR #1](https://github.com/vicliu624/Foreshadow/pull/1).
Official downloads and the signed catalog are published only after the frozen-source
gates below pass. The Release's attached qualification manifest records actual
results, source SHA, artifact hashes and external limitations; this source document
does not replace that evidence.

This version adds the bundled [1090 MHz ADS-B module](../adsb.md): periodic
detection, continuous PPM/CRC processing, offline recovery evidence and an
aircraft map/list workspace. The module owns reception requirements, decoding,
bounded queues, descriptions, translations and offline Natural Earth map assets.
Existing receiver, recovery and desktop consumers retain their generic protocols.

The ADS-B implementation was tested in the 0.2.12 local build on ARM64 uConsole;
14 selected tests passed, including architecture and existing recovery/live
research regressions. A paced 30-second synthetic stream recovered 3000/3000
frames without software input rejection. Native map, language fallback,
restart-layout and Unicode-path checks passed. These observations are not
0.2.13 frozen-source platform acceptance or physical RF/hardware-loss evidence.

The local ADS-B build excluded television; a public update must retain the
complete existing feature set, including DTMB and the pinned media dependency.
Physical 1090 MHz capture did not yield valid frames and reported a PLL warning.

## Publication gates

- Freeze this version's source and collect matching reviewed dependency materials.
- Build and test each published platform, extracted Unicode-path archives and
  application/toolbox upgrade transactions through the existing release workflow.
- Verify compatibility with the catalog URL and trust key compiled into target clients.
- Sign the verified catalog locally with the existing matching key; never put the
  private key into Git, CI artifacts or remote machines.
- Publish packages, corresponding source and signed `catalog.json` together.

The update application ID remains `org.amc.ams`; settings roots, file formats,
package IDs and receiver protocols remain compatibility identifiers.

## Platform and material baseline

The reviewed release selection covers Windows x64 (Qt 6.8.3 / OpenSSL 3.6.5),
Debian 13 x64 and Debian 13 ARM64 (Qt 6.8.2 / OpenSSL 3.5.9 SDKs). Windows uses
the recorded vcpkg revision; Debian jobs compare installed SDK source identities
with the delivered `.dsc` files before building. Both Linux architectures require
their own native build, extracted archives and package transactions. The uConsole's
RPi-modified OpenSSL runtime is separate from the generic Debian build SDK, and
compatibility is checked using the actual ARM64 release artifact. macOS is not
part of this publication selection.

The complete base retains FM, the waveform laboratory, DTMB and the pinned
television/media dependency. The SDRplay network client and other independent
toolboxes remain separate packages. Vendor APIs/drivers and firmware are not
included. Natural Earth map provenance/public-domain notices accompany the base.
The existing codec assessment remains applicable; publication does not establish
new patent grants or a general free-download exemption.

## One-time migration from older AMS installations

Older AMS clients can still contain the retired `vicliu624/AMC` catalog URL.
That deleted repository cannot discover releases in `vicliu624/Foreshadow`.
Download the complete qualified portable archive for your platform, extract it
to a new application directory, and start that copy. Keep the former installation
until the new application and required receivers have been checked. Preserve
recordings and user settings outside application directories; existing settings
roots and package IDs are retained. No private signing key or vendor API file is
needed from a user for this migration.

The new application uses the Foreshadow catalog URL and the existing public trust
key. Do not edit the trust anchor or accept an unsigned catalog to bypass migration.
