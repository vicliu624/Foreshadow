# 架构与接口设计

[English](03-architecture-and-interfaces.md) · 简体中文

生产技术栈为 C++20/CMake 与 Qt 桌面；Python 用于工具和可选测试，不承担生产采集/DSP。目录与目标见[源码地图](../src/README.zh-CN.md)。

Foreshadow 是以插件驱动的宿主。大部分领域功能由提供者拥有，会话、通用 DSP、持久化及桌面/CLI 消费者提供共享基础设施。[插件指南](plugins.zh-CN.md)对应说明当前静态组装、运行时模块和外部工具的交付形式。

## 所有权与数据流

接收机提供者通过公开接收/流协议产生不可变编码 I/Q 块；接收会话仲裁整套配置需求和独立租约。采集、录制、检测、实时研究及显示分别拥有有界生命周期与计数。

录制来源提供者通过原生路径载入分段窗口。通用 DSP 负责编解码访问、滤波、有理重采样、波形/窗口计算、模型拟合和恢复结果验证；实际信号方法属于模型/恢复提供者。桌面和 CLI 消费通用描述/结果。

| 变化轴 | 所有者 | 稳定消费者 / 组装 |
|---|---|---|
| 硬件事实/参数 | 运行时接收机提供者 | 注册表/会话；提供者构建注册 |
| 检测语义 | 检测描述/提供者 | 通用事件及快照调度；调制注册表 |
| 文件容器 | `SignalSourceProvider` | 窗口/工作器；来源注册 |
| 编码/满量程 | 样本编解码 | DSP、录制和视图 |
| 参考生成 | `ReferenceModelProvider` | 通用比较/模型 UI；模型注册 |
| 同步/成帧/校验 | `RecoveryProvider` | 通用恢复/UI/导出/保存；恢复注册 |
| 原生实时面板 | `LiveResearchProvider` | 通用宿主/工作区；`live_registry.cpp` |
| 分发包类型 | 类型适配器 | 通用安装器/中心；包类型组装 |

## 核心契约

样本序号为整数，区间左闭右开。源流、文件偏移、处理时钟及绘图时间分别表达；有理映射与滤波支撑明确，缺口不补零。超时使用单调时钟，UTC 标明来源。

编解码拥有字节数、解析、归一化和满量程。目前包括 CU8、CI16-LE、CF32-LE；未知/截断拒绝，不能将非 CU8 当 CI16。

事件保留通用名称、特征和未知字段。恢复描述符号/比特/字节/帧/测量及源依赖；复数使用恢复/证据 v2、外层分析 v8。支持的旧契约继续读取，新能力明确升级，不静默丢字段。

## 资源与并发

队列按实际字节/时间预算；采集不等待可选研究/GUI。录制耗尽明确停止；分析过载记录未分析输入，不冒充“无信号”。状态复制已发布快照，不等待其他 DSP；共享不可变结果原子发布。

长文件按需有界读取，预算覆盖 FFT、矩阵、结果容量和 JSON。完整分辨率有效数据用于测量，绘图只减少显示图元。取消和会话代次防止旧任务覆盖新结果。

## 持久化与部署

SigMF 保留原始/派生身份与父支撑。分析配置保存已应用处理及源身份，不把缓存结论当权威；重开重新计算并报告缺失/变化。工作区只恢复一次，缩放不重建布局。

签名目录、传输、类型适配、通用安装和应用激活分别负责协议。运行库/资源在提供者/构建组装位置声明；新 Mac 包为 `Foreshadow.app`，配置/工具箱/CLI 标识保留兼容。

## 独立接收机服务（0.2.12）

基础应用与可选 SDRplay 服务客户端工具箱分别交付，厂商 API/驱动仅由独立安装的接收机服务加载。
提供者所有的连接描述和请求协议 2 在设备枚举前传递地址，界面、会话和 CLI 保持通用。
固定 BSL SoapyRemote 客户端依赖 SoapySDR 0.8.1，支持离线覆盖
`FETCHCONTENT_SOURCE_DIR_SOAPYREMOTE`。只有声明为随主体捆绑的提供者进入基础归档；
原始 CMake 安装目录是组装暂存树，不是已验收基础归档。SDRconnect 评估、安装、协议、连续性和
许可边界见[接收机服务](receiver-services.zh-CN.md)。
