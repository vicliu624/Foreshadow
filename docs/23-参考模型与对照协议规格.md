# 参考模型与对照协议

[English](23-reference-model-protocol.md) · 简体中文

PSK/OFDM 自动接收、信道估计、均衡和符号 EVM 属于规格 25 的独立恢复提供者；本规格的显式时域参考对照继续保留原有定义，拟合残差不重新命名为 EVM。

本规格落实规格 22 的 P2，不宣称模型拟合等于识别或解码。实现及验收进度继续写入波形实验室实施记录。

## 边界

模型的参数描述、整套校验、参考生成、参数估计、方法说明与资源属于模型提供者。通用比较内核只消费提供者准备的纯参考函数及协议字段；工作区、后台作业、参数编辑器和结果视图不导入具体模型，不按模型 ID 分支。静态组装位置为 `plugins/research/models/registry.cpp`；同类新模型增加提供者、资源与注册，独立提供者应通过原有比较路径。

通用比较拥有已声明的拟合自由度：手动时间偏移、有界整数采样延迟搜索、可选复数增益以及可选复数直流偏置。模型物理参数估计仍属于提供者，不能在消费者中按模型补规则。参数草稿与已应用结果分开；依赖针对完整待应用配置及实际输入时钟求值。

## 数据与数值

`ReferenceModelProvider` v1 提供版本化的参数描述和准备函数。准备结果带完整参数、方法及可复用的纯样本函数，或者带资源 key 的结构化问题。纯函数接收相对整数采样位置、实际采样率及显式时间偏移。模型时间原点是所选分析区间起点；绝对源序号不转为 double。已有处理信道的有理原始位置继续由输入分析时钟提供。

v2 增加针对整套待应用参数的描述函数、实际时间对齐上下界与提供者工作区预算。旧 v1 描述及比较接口保留；v1 没有声明的提供者工作区显示未知，不能当作零字节或完整资源保证。v2 提供者在准备阶段检查剩余预算，声明闭包/参数前缀等载荷，通用内核与候选表的实际 capacity 合计核对。界面依据完整待应用描述更新数值范围，已有非法值保留并显示问题，不静默夹断。

v3 保留 v2 的描述与工作区能力，将参考求值点的整数延迟和手动秒偏移分开。分段 PSK/OFDM 符号边界不能先把整数延迟变成浮点秒再推回样本；新提供者使用 `offset_samples()` 或 `seconds()`，整数部分先与相对样本位置相加。v1/v2 仍接收原有的合并秒偏移，整数新字段为零，不能把新调用语义静默施加给旧实现。比较记录保存提供者协议与延迟编码方式；这是通用协议版本分派，不是模型 ID 分派。

结果保留不可变观测、精确区间、提供者/方法/参数版本、对齐与拟合选项、实际比较点数、参考与残差轨迹、拟合复数系数及误差。参考是生成数据，不能保存成另一份原始观测。参考/残差只为实际选中的点分配数组，共享 `AnalysisTrace` v4 的紧凑映射；原分析和有理原始位置不改变。缺口不补零，选区外不分配伪造的观测，参考时间在缺口两侧仍由原分析时钟定义。低幅度对相位/频率推断的限制不等于原始 I/Q 不可比较。

拟合复数增益为最小化 `sum(|y-g*x|²)`；同时拟合直流时求解 `sum(|y-g*x-d|²)`。零参考能量、参考与常数项无法区分、非有限输出或预算不足必须给出失败，不伪造完美结果。每个延迟候选使用相同观测点及同一组自由度，按实际残差比较；记录并列候选。自由相位下的纯音延迟通常不可辨识，不能将任意并列点显示为已找到唯一同步时刻。

报告复数残差 RMS 与相对于输入 RMS 的比值；输入能量为零时归一化比值不可用。它不是 EVM。PSK/OFDM 的 EVM 需要另行提供已知参考、符号/载波同步、均衡及有效区条件，缺少条件时不显示 EVM。生成或拟合噪声并不确立载波、信噪比或业务语义。

输出按实际 vector capacity 计量，参考/残差轨迹纳入后台联合载荷预算；候选数量、参考函数求值次数与时间跨度分别受限。计算可取消，只发布完整结果。共用现有串行后台队列，不另建长期保留多代输入的模型流水线。

模型后台作业可复用已完成的不可变原始/信道分析。窗口研究与模型各有应用区间，单独更新一个不重算或丢弃另一个。基础信道处理、窗口计算及模型比较依次执行；模型开始前按仍存活的实际波形、信道和窗口载荷计算剩余额度，再约束生成器工作区与输出，不为已经结束的 FIR/FFT 临时工作区永久预留。v1 缺少生成器工作区声明的提供者仍可使用原数值兼容接口，但不能冒充具备 v2 的桌面联合预算保证。

## 桌面工作流与配置 v6

模型对照为波形实验室的实际轨迹页，参数区使用注册表和提供者的整套描述自动生成。观测输入可选原始窗口或已提取信道；应用时取该输入的当前视区，在共享串行后台作业上执行。参考 I/Q 与实际 I/Q 叠加显示，残差有独立轨迹及 I/Q 平面。生成轨迹与观测分别标识，不把参考写成新采集样本。窗口研究和模型分别持有自己的已应用区间。

对照时间原点在应用时固定。模型页缩放只改变查看范围并可定位关联源范围，不重拟合；源光标经原有有理时钟映射，未比较处的残差不可用。固定延迟、搜索歧义以及仅在有限搜索域内唯一分别显示；最后一种仍不是符号同步。模型参数与对齐控件是草稿，保存只取完成结果中的实际参数与自由度。取消、错误模型或重开失败保留已有完成结果。成功替换原始/信道输入后，旧模型失效；定位长文件的原始邻域时，若处理链和时钟保持，重算并保留已应用的处理后模型及视图。

启用模型的分析使用 `org.amc.waveform-analysis` v6，保留 v1–v5 的来源、相对路径、身份摘要、处理链与视图语义。所属 `model` 配置 v1 保存提供者 ID、方法版本、完整参数、原始/处理后输入、十进制字符串的应用区间、实际输入时钟、全部拟合选项和资源限额、方法记录，以及独立视区/光标/页面。方法记录包含提供者的未知方法字段及误差/拟合事实，作为当次完成结果的记录；重开仍根据已验证输入重算，不把该记录当作可覆盖实际计算的结果。未知提供者、不支持的方法版本、不匹配的输入时钟或非法整套参数不能静默替换。保存器只处理通用来源与原子配置事务，不解析具体模型。

模型和窗口研究页面不显示只适用于原始/信道轨迹的概览及缩放行。紧凑窗口中轨迹、参数分别滚动，长解释置于参数区，不能因说明挤占而只剩不可检查的曲线碎片。面板显隐及停靠仍由通用工作区负责，模型页不重置用户布局。

## 交付与验证

先完成通用数值/扩展协议及独立提供者契约，再接入常量、AM、FM、2-FSK、线性 Chirp、LoRa 参考，随后处理 PSK/OFDM 明确参考条件。通用参数编辑器渲染所属描述和资源；模型面板只在能够完成实际比较后出现。保存与重开配置必须重算并验证原始输入，保留方法版本、应用参数、拟合自由度及结果区间。

第一批六个提供者为恒频复载波、正弦 AM、正弦 FM、矩形频率脉冲的连续相位 2-FSK、非循环线性 Chirp 及循环单符号 LoRa Chirp。FSK 只使用显式比特图案；LoRa 的 SF、扫频宽度、符号及方向均显式给定，不含报文结构或解码。LoRa 参考依据 [Chiani 与 Elzanaty 的连续时间相位积分](https://arxiv.org/html/1906.04256#S2.SS1)，保留回绕处的连续相位。瞬时扫频宽度不被当作已验证的占用带宽。各模型名称、说明、字段、整套问题及方向选项随自身资源分发。

后续两种 v3 提供者为已知符号 PSK 和已知子载波 OFDM，消费者继续使用同一参数、后台、对照和配置路径：

- PSK 支持 M=2/4/8/16，显式十进制符号索引映射至 `exp(j*2*pi*k/M)`，不推断比特或 Gray 映射。矩形脉冲保持对应符号；RRC 为以 `k+0.5` 符号时刻居中的连续根升余弦，滚降 0–1、对称截断跨度 2–32。其连续未截断脉冲在符号时间中的能量为一，截断后不重新归一化。有限序列必须覆盖整个对齐域及全部 RRC 相邻支撑；重复只在用户显式选择时成立。
- OFDM 显式提供每个符号的 `bin:实部,虚部`，空格分隔 bin、`|` 分隔符号。未指定 bin 明确为零参考。有效长度 N=8–4096、循环前缀 0–N、采样时钟为实际输入时钟，子载波间隔为 Fs/N。实现采用 `sum(X[k]*exp(j*2*pi*k*n/N))/sqrt(N)` 的酉归一化；前缀来自该符号末尾。逆变换与前缀结构可参阅 [MathWorks OFDM 调制说明](https://www.mathworks.com/help/comm/ref/ofdmmod.html)，本文的归一化由上述公式单独定义。有限符号之外无参考，覆盖不足拒绝比较。

PSK 最多 256 个已知符号；OFDM 最多 16 个符号、每符号 64 个指定 bin、合计 256 个。输入文本各最多 4096 字节，OFDM 复数分量位于 −10…10，重复 bin 和非有限值拒绝。先有限扫描数量，再按实际 vector capacity 分配和计量生成器状态。RRC 每次求值至多 33 项，OFDM 至多 64 项；通用求值上限计量的是参考函数调用次数，不是固定耗时或持续吞吐保证。

两者记录已给定的参考、手动时钟/边界，以及尚未建立的载波/符号同步和未执行的均衡。当前对照仍为时域样本（OFDM 包含显式前缀），不显示符号或子载波 EVM。EVM 还必须明确参考和归一化，相关定义见 [MathWorks EVM 算法说明](https://www.mathworks.com/help/comm/ref/comm.evm-system-object.html)；本项目的“残差 RMS / 输入 RMS”不会因选择 PSK/OFDM 而自动改名。以后增加符号域测量需要显式协议、有效区及同步/均衡证据，不能依赖用户勾选或模型名称伪造这些条件。

验收包含独立公式真值、已知复数增益与偏置、错误参考、缺口、大整数绝对时钟、处理后有理时钟、并列延迟、退化参考、零输入、预算及取消。独立新模型及资源增量必须进入原有比较和展示路径。真实录制用于检查工作流和反例，不能替代独立真值或证明未知设备用途。
