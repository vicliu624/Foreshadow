## 所有权与扩展边界

变化轴是接收方法、训练/导频协议、复数测量及其显示。接收方法、整套参数校验、同步、信道估计、均衡、判决与测量规则由 `plugins/research/recovery` 的各提供者维护；注册表是唯一组装位置。通用恢复协议所有者为 DSP recovery；桌面恢复面板、保存工作器和证据导出是稳定消费者，不按 PSK、OFDM 或提供者 ID 分支。语言由提供者随包资源维护。

恢复协议升级到 v2：增加有明确测量域的复数序列，逐点保存组号、坐标、有效性和依赖；参考点明确标识为生成的参考，不能当作新的观测。v1 提供者及旧分析档案继续兼容。v2 结果导出采用证据 v2，保存配置采用分析 v8，旧消费者须显式拒绝，不能静默丢弃复数数据。

## 接收与测量

自动同步的前提是已声明波形族及训练配置，不等于盲识别任意无线协议。BPSK/QPSK 声明符号率、脉冲形状、训练符号和数据长度；接收机自动寻找帧起点、分数定时和载波偏移，训练区估计有效信道及有限长线性均衡器，后续数据进行相位/定时跟踪。OFDM 声明 FFT/CP、两帧重复训练、活动子载波和导频；接收机自动完成 CP/训练同步、频偏消除、逐子载波信道估计与均衡，并用导频跟踪公共相位及采样时钟造成的相位斜率。边界外、失锁及深衰落必须保留未知状态。

训练和导频用于估计；已知数据参考只用于测量，不能参与同步、信道或均衡拟合。未提供已知数据时可给出判决参考 EVM，必须披露来源及其不能衡量误码率的限制。测点为均衡、相位校正后的数据符号；训练、导频、无效点及均衡瞬态不进入数据 EVM。RMS EVM = `100 sqrt(sum |z-r|² / sum |r|²)`；峰值使用同一平均参考功率归一化。有效点少于八个、排除点超过总数据点的 20% 或失锁时不发布可用 EVM；有效点与排除点数都必须显示。低 EVM 不能替代 CRC / 应用校验，恢复字节仍为候选。

有效信道是输入分析时钟及声明脉冲下的估计，不是校准射频传递函数。每个点的来源包括实际窗口和参与估计的训练/导频支持；不跨缺失样本补零，不伪造单样本精确时间。

## 验收

独立发射真值覆盖定时、分数/整数频偏、相位、采样偏差、多径、噪声、保持数据的误码与 EVM；负例覆盖错误训练、无信号、深衰落、间断、取消和资源限制。测试不得调用接收算法产生真值，不得把训练拟合残差当作 EVM。另用独立非调制提供者证明复数协议、通用界面、导出、保存重开无需增加 ID 分支。

按容量计算结果和工作空间，按操作预算限制搜索、矩阵及 FFT；JSON 使用独立字节/节点/深度预算。桌面复数图最多显示 16384 个测量/参考点，完整点仍保存在表格与证据中；绘图抽样不参与 EVM 计算。完成架构、契约、现有回归和 Windows/Linux 实际发布包的 Unicode 路径验证；评审用例须经真实界面保存、重开、定位及导出。

定义参考：[MathWorks EVM](https://www.mathworks.com/help/comm/ref/evmmeasurement.html)、[GNU Radio Symbol Sync](https://wiki.gnuradio.org/index.php/Symbol_Sync)。这些定义不构成任何空口标准兼容声明。
