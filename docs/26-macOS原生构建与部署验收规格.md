# macOS 原生构建与部署验收

[English](26-native-macos-acceptance.md) · 简体中文

用户提供原生 Mac 环境后，本轮恢复 macOS 部署验收。目标机器为 Intel x86_64、macOS 14.3.1，不能沿用托管发布流程中的 Apple Silicon / macOS 15 假设。构建、测试、实际包和桌面流程必须分别留证；本轮不上传正式发布，也不修改发布私钥。

## 变化轴与所有者

本轮发现的兼容变化轴是标准库的共享指针原子发布能力。发布状态由捕获缓冲和研究后台各自拥有；接收机、检测、恢复提供者及界面仍消费原有快照/完成结果，公开协议不变。`SignalCapture::State`、`RecordedWaveformWorker`、`WaveformAnalysisSaveWorker` 的内部成员使用标准共享指针原子操作，沿用媒体播放已有做法，使尚无 `atomic<shared_ptr>` 特化的 libc++ 能编译。

所有并发读取、存储和交换均通过标准原子函数完成，默认顺序一致性不变；不能混入普通并发读写，不能扩展锁范围到采集、DSP 或文件操作。新增兼容条件不按平台、接收机或调制 ID 散入稳定消费者。构造完成的可变结果在发布时转换为只读共享所有权，不能发布后修改。

## 构建和验收

复用机器已有且经独立 C++20 编译/运行探针确认的 LLVM 21；系统 Apple Clang 15 缺少本项目使用的线程设施，不修改系统 SDK 或系统应用。Qt 使用与该系统兼容的 6.8.3。依赖及源码归档校验后进入独立缓存目录，部署目标下限和实际 Mach-O 下限必须核对。

完成 Mac 全量 CTest、Cocoa 原生宽屏/缩放/紧凑流程、六份便携样例保存重开、证据/已知字节导出；真实应用归档在中文及非 BMP 路径验收主体、模块和独立工具箱。审核每个 Mach-O 的外部依赖、最低系统版本和包内闭合引用，验证重定位及本地签名。没有验证的设备采集与 Apple Silicon 架构单列，不以模块可加载代替硬件可用。

并发兼容改动还须通过 Windows/Linux 现有捕获、后台和保存回归，以及仓库适用的架构检查。若平台故障要求调整包组装，只能在声明的 CMake/分发组装位置实现，不能把兼容分支放进界面和研究算法。

非系统工具链通过 `AMC_MACOS_EXTRA_RUNTIME_LIBRARIES` 声明完整 dylib 闭包，通过 `AMC_MACOS_EXTRA_RUNTIME_LICENSE_FILES` 声明随包通知。应用和独立研究提供者在各自 CMake 组装位置安装这些资产，重定位按每个加载者计算相对路径；系统 `/usr/lib`、`/System/Library` 引用保留系统语义。符号链接去引用后以声明的加载名称分发，不能依赖开发机 Homebrew 路径。通用工具箱安装器和界面不识别这些运行库或提供者名称；真实包审计必须覆盖独立工具箱的全部 Mach-O。新增工具链使用同一声明，不增加运行库名称分支。

Mach-O 审计区分文件依赖与搜索目录：`LC_RPATH` 中不带后缀的 `@loader_path` / `@executable_path` 是合法目录；不能把目录要求成文件名，也不能因此放过非系统绝对路径或缺失的实际 dylib 依赖。

重定位在签名之前完成。应用包由包组装者最后递归签名，不能在其余嵌套程序尚未签名时把主入口当作普通文件逐一签名；独立进程和相邻运行库使用明确的叶子签名模式，再分别核验。

功率报告提供者将自己的运行库和通知文件列入已有 `resources` 协议，并生成相应开发/安装资产。保留的资源清单安装兼容接口和受管工具箱必须复制同一份声明的完整载荷；既有通用安装器无需识别库名称。GUI 回归夹具按声明组装实际外部工具，不能只复制可执行文件及某一个已知目录。界面继续使用受控工具箱中心，不重新开放任意本地导入。Mac 可分发树由应用包与独立工具箱载荷组成，原始 CMake 安装目录中另供开发使用的 `bin` / `libexec` 副本不冒充第二套便携应用；实际分发树内每个 Mach-O 仍须审计。

Qt 部署工具将已安装的 `Foreshadow.app/Contents/Frameworks` 纳入搜索，解析同一组装位置内的提供者运行库，不依赖媒体 SDK 的开发路径来解析已经随包安装的 FFmpeg。

波形实验室的文件范围编辑属于原始观测与目标信道页，模型、窗口和恢复页使用其自身的分析范围入口，保留来源说明和精确支撑坐标。工具栏采用系统小图标尺寸。此调整只改变提供者内部内容，不按缩放或窗口尺寸重新应用工作区布局；Cocoa 640×480 必须继续满足数据区可见高度、参数可访问和坐标不裁切检查。

通用复数证据页使用可滚动容器，在小窗口下保留测量表、平面/组选择及星座图的自身空间，禁止压缩成相互遮挡的控件。平面选择器按有限显示宽度缩放，完整选项继续通过下拉列表访问。PSK/OFDM 原生流程必须滚动到测量和图并验证可见区域；独立复数提供者的已知点必须在可见区域中完成点击与精确定位。不能仅以结果数值正确或截图文件存在判定紧凑界面通过。

捕获测试保留普通 CTest 的两秒范围，另提供 `signal_capture_test --sustained-seconds 180` 执行单次连续输入，逐次核对实际队列/保留预算、接受与拒收计数及冻结后的不可变性。该输入为明确 1 MS/s 的合成源，不依赖设备；不能把它当作硬件无丢样或其他速率性能保证。

媒体界面暂停契约先等待独立夹具进入实际音视频播放，再在不处理任何 GUI 事件的 300 毫秒内比较已发布进度。固定睡眠不能证明播放器已启动；启动等待有五秒上限，失败保留状态，播放期间停止前进仍失败。另用延迟一秒启动的同一协议夹具验证初始化延迟不会冒充播放停滞，不能通过跳过媒体契约或放宽播放连续性断言完成平台验收。
