# 信号恢复与证据协议规格

[English](24-recovery-and-evidence-protocol.md) · 简体中文

本规格落实规格 22 的 P3。交付范围为事件、输入采样、处理链、符号/比特/字节、帧校验与结论的可追溯工作流，包含实际桌面浏览、定位、保存重开及导出。各恢复提供者、真实调查和平台验收分阶段记录；新增 PSK/OFDM 接收与 v2 复数工作流的最新证据见[接收与 EVM 验收](reports/2026-11-12-PSK与OFDM接收验收.md)，历史初始接入状态不能用作当前缺项列表。

## 所有者与边界

变化轴为恢复方法、帧协议及其解释。`RecoveryProvider` v1 拥有完整参数描述、参数校验、同步/判决/映射/纠错/去白化/帧组装、质量门槛、校验条件与语言资源。组装位置为 `plugins/research/recovery/registry.cpp`。`recover_signal`、证据验证器、后续后台和桌面仅消费协议，不导入具体恢复器，不按调制或工具 ID 分支。

本协议是静态 C++ 协议，不是运行时二进制 ABI。提供者必须声明受支持的协议和方法版本；不能将新的结果能力假装成已有枚举。参数与可见说明来自提供者资源。检测事件作为不透明 JSON 保留，不因主体不了解其模块 ID 而删除特征或结论。

### v2 复数测量扩展

规格 25 增加恢复 v2；消费者同时接受 v1 和 v2，拒绝未来版本。v1 的数字/测量能力及字节导出语义不变。v2 增加 `complex` 序列、测量域资源 key、生成参考标志以及逐点符号组和有符号坐标；测量结果可携带复数序列，仍不得携带数字序列或帧。数值必须有限，未知点必须保留原因；生成参考必须依赖实际测量序列，不能作为观测叶节点。

v2 的标量 `RecoveryMetric` 带 ID、资源标题、单位、可用性和不可用原因，由通用测量表显示；稳定消费者不解释具体提供者 ID。所有新增字符串和容器容量进入结果预算。证据导出声明 v2；未知复数的 value 为 null，候选复数与组/坐标保留。复数视图通过同一个依赖 DAG 定位来源。

恢复配置 v2 保存提供者协议版本、方法版本和复数平面/符号组选择，外层分析 v8 明确声明该能力；旧 v1–v7 档案继续读取，低版本伪装携带新能力必须拒绝。独立非调制 v2 提供者必须在不改界面或导出器的条件下通过显示、资源回退和配置重开检查。

## 输入与结果

输入为已有不可变 `WaveformAnalysis` 和精确选区，使用该分析的实际采样时钟。原始 I/Q 已经由编解码接口归一化；恢复器不再解析存储编码。处理后输入继续使用有理源位置，不能以处理下标冒充原始样本。来源身份及摘要由已有来源/后台/分析配置拥有，恢复内核保留实际分析指针和事件；后续保存重开必须同时验证其输入身份及完整处理链。

`RecoveryData` 区分数字、测量及不支持三种能力。测量或不支持结果不能携带数字序列/帧；宿主只有数字能力到达字节阶段才提供 Hex/ASCII。恢复结果保留提供者、方法、实际参数、方法记录和事件未知字段，样本本身不被替换。

处理阶段有 ID、资源标题、上游阶段索引、参数、特征及结论。阶段按拓扑顺序给出，上游只能指向更早阶段。符号、比特和字节序列分别声明阶段及类型；每个值保存已知标志、数值、阶段定义的度量、不可用原因 key，以及输入选区上的支撑范围或更早序列的依赖范围。度量不自动解释为置信度。多个符号到一个比特、去交织或纠错造成的多级依赖通过相同 DAG 表达，消费者不增加算法分支。

叶节点支撑是“所需输入范围”，可能包含缺口；不等于该范围内每个样本都已观测。擦除原因和父分析缺口继续可见。`recovery_input_ranges` 按依赖追溯到这些输入范围，保留 64 位整数，不以浮点时间往返；随后由父分析转换为精确原始位置。重叠或相邻的所需区间合并为精确并集，分离区间之间不填空白；父分析仍负责实际观测及连续性。追溯有访问与输出范围限额，不无界展开或填充未观测样本。

## 字节与帧的证据状态

未知比特/字节保留已知标志和原因，存储中的数值不构成已恢复数据。后续 Hex 显示未知字节为不可用，二进制导出不能静默用零替代。部分字节和部分符号均有明确状态，不能因为槽位数凑够八个而判成完整字节。

帧状态为候选、已验证、无效、截断。校验分别为未知、不适用、未携带、通过、失败，带所属阶段、是否为必要条件及原始证据。已验证帧必须有验证范围资源 key、至少一个通过的必要检查、全部必要检查通过、没有失败检查、相关字节全部已知。未携带的可选 PHY CRC 可以与通过的应用校验并存，但不能成为“PHY CRC 已通过”的声明。校验一致性检查不推断设备身份、业务含义或加密状态。

纠错应保留判决序列、纠正后序列、依赖及所属校验证据；不能覆盖原错误而使弱候选与严格帧无法区分。新 LoRa 恢复器仍需依据最新调查资产验证 PHY、应用校验、歧义与修复，不能借当前固定 FSK 帧的通过结论替代。

## 资源边界

默认结构化载荷为 8 MiB、算法工作区为 1 MiB、输入最多 1M 时钟位置、总值 131072、依赖 262144、帧 4096、阶段 64、序列 16、运算 64M。结构化输出按实际 vector/string capacity 计量，不能仅计可见值的 size。JSON 单独限制累计序列化字节 64 KiB、节点 2048 和深度 16，序列化前先限制原始字符串与 key 总量；这些是 JSON 结构/线格式预算，不是对其标准库分配器开销的精确测量。后续后台联合预算必须保留这种区别，不宣称当前内核测得了整进程堆内存。

提供者在分配和计算前检查自己的预计输出/状态及运算预算，完成后通用验证器再核对。取消前后均不得发布部分结果。当前内核没有创建新线程或持有新的采集使用权；后续桌面作业应接入现有串行后台，保留上一份完成结果的失败/取消语义。

## 首个明确条件的恢复器

### 桌面、作业与配置

恢复面板作为实验室的第五个结果页面，参数区使用已有通用编辑器及提供者的完整描述；界面、后台、保存器与通用导出器均不按恢复器 ID 分支。Hex/ASCII、帧与校验、符号/比特/值、处理阶段与事件分别浏览。表模型按行提供数据，不为每个符号建立 QWidget。未知字节显示 `??`，校验状态与必要条件单独可见；非数字结果隐藏数字页面，仍保留阶段及未知证据。

恢复请求进入现有 `RecordedWaveformWorker` 的串行运行/最新待处理队列。应用快照固定实际输入、精确范围、方法版本、参数及事件；窗口或模型更新复用该不可变恢复结果，成功替换基础输入才使旧结果失效。失败及取消保留上一份完成结果。联合预算计入仍存活的波形、窗口、模型、恢复 capacity 载荷、恢复工作区及单列的 JSON 线格式 allowance；该 allowance 不是 JSON 分配器或整个 Qt 进程内存的精确上限。

点击字节、值或帧选择其依赖的所需输入区间，定位动作使用整数分析时钟。处理后选区直接设置处理时钟光标，原始位置保留有理分数；查看预览之外的原始邻域通过已有文件按需读取流程，保留同一处理链的已应用结果。多个不相邻支撑区间的总览可以覆盖其中空白，但不会向轨迹补入观测，区间数量和缺口提示继续显示。

分析配置 v7 / 恢复配置 v1 保存已应用的提供者、方法版本、参数、方法记录、精确范围、实际输入时钟、限额及页面/帧/序列选区。未应用草稿不进入配置。重开重新计算并核对来源摘要、处理链、时钟及方法版本；未知提供者和不匹配协议不能被替换成默认方法。冻结内存来源仍走既有样本归档、回读验证与原子配置事务，v7 不降级，保存不停止采集。

### 证据与字节导出

`export_recovery_json` 的线格式为 `org.amc.recovery-evidence` v1，包含来源分析快照、恢复实际时钟/范围、方法与参数、事件、阶段、全部序列值/支撑/依赖，以及帧/字段/必要检查和验证范围资源 key。所有样本位置、数量和恢复整数值使用十进制字符串，避免阅读端经浮点数丢失精度；序列索引保持受限整数。未知值输出 `known=false` 和 `value=null`，原存储值只在 `candidate_value` 下保留，不能冒充恢复字节。未知事件、方法及字段原样保留。

导出器流式序列化，使用 32 KiB 缓冲，不复制整份值/依赖图为第二棵 JSON 树；默认总线格式限额 64 MiB，来源分析信封另外限 8 MiB，取消与 sink 失败向调用者传播。完整结果仍通过通用恢复验证。二进制导出只接受非空、全部已知的字节子集，逐字节保持原值；可以导出校验失败帧的已知候选字节，不能把此能力解释成有效帧声明，也不能用零填未知字节。

界面通过现有单一文件工作线程执行导出，快照与选区在打开对话框前固定，使用 `QSaveFile` 原子提交并保护元数据和原始数据文件。失败/取消不发布部分文件，配置保存与导出有独立完成状态。JSON 不包含完整 I/Q；临时内存来源明确标注关闭后不可获得，只有“保存当前分析”及其样本归档流程才能使其持久可重开。字节文件本身不携带校验或业务语义，证据应结合 JSON 保留。

### 当前明确条件

`manual-2fsk-fixed-crc16` 使用手动整数符号网格、两个输入频率、归一化 RMS 门槛、频率投影分离度、字节内比特顺序及载荷长度。每符号进行两个非相干复数频率投影；低功率、判决不分离、缺失或未知连续性边界产生擦除。正常短读边界不重置投影，不影响判决。输入末尾的部分符号显式标为不完整。

0/1 频率分别映射 0/1，按指定顺序打包字节。固定帧为给定长度载荷加两个大端 CRC 字节；CRC 多项式 0x1021、初值 0xFFFF、xorout 0、不反射。没有 FEC。每次选区最多 64 帧，仍受通用预算约束。CRC 通过只验证这些手动网格、长度和映射假设下的关系；没有自动捕获、协议识别、硬件连续性保证或设备/业务归因。

验收使用独立已知字节的连续相位 FSK 和 GF(2) 整体多项式除法生成校验，不调用恢复器来生成真值。检查原始/有理处理时钟、短读不变性、错误位/顺序、缺口、未知连续性、低功率、截断、预算与取消。另用独立成对实轴二元提供者验证多级依赖、候选字节和未携带校验；独立测量提供者验证非数字结果不被强制变成 Hex。实际界面、独立提供者及资源增量显示、保存重开和导出已补充独立合成真值验收，具体命令与原生范围见[实施记录](reports/2026-11-11-波形实验室实施记录.md)。这些结果不代替真实空口录制、其他平台、发布包及持续硬件输入的验收。

## LoRa PHY 的有限 I/Q 假设恢复

`bounded-lora-phy` 已在声明的恢复注册与构建位置组装，参数与中英文资源随提供者分发。通用界面、后台与导出器没有增加 LoRa ID 分支。提供者消费实际分析时钟下的归一化 I/Q，要求每 chip 1/2/4/8/16 点、FFT 最多 262144 点；可先使用已有目标信道把长文件变为合适的采样率。声明 SF、带宽、首个数据符号偏移、可选前方上 Chirp 参考、频偏和 I/Q 方向，不能把任意 FFT 峰视为自动 LoRa 识别。

完整符号支撑经解 Chirp、有限补零 FFT、别名功率折叠及局部三点分数峰插值；普通短读不打断符号，缺口/未知连续性或不完整支撑不补零为完整观测。归一化 RMS 与折叠峰集中度由提供者维护，不当作校准后的 RF 功率、SNR 或概率。参考上 Chirp 不可用时，相关符号保持未知。

时间网格最多九个位置，时间/漂移/bin 偏差组合最多 32768 个。显式头检查只筛选配置假设，随后依据 PHY CRC、截断、未知字节、头与载荷观测距离等明确记录的分数排序；结果不是无限域最优或业务识别。相同字节内容合并等价参数假设，最多保留 32 个不同候选；丢弃了较差内容与最佳集合不完整分别报告。最佳内容冲突时只保留一致字节为已知；最佳集合不完整时全部载荷字节未知。没有 PHY 载荷 CRC 的唯一候选仍不升级为验证帧。应用 CRC/成对编码/补和尚未进入此 PHY 提供者。

原始 FFT 观测、全局假设节点、对齐符号及后续编码分别进入通用依赖图。全局节点引用搜索使用的观测，字节定位包含相应参考及搜索上下文，参考与数据之间的未观测时间仍为空白。通用追溯按唯一节点展开共享依赖，避免一个校准节点被每个比特重复展开；节点及待处理任务仍受访问限额约束，不声明整个标准库堆的精确上限。

FFT 输入/输出、查询到的实际计划空间、参考数组、折叠谱、峰/候选 capacity、字符串余量及编码临时状态先准入再分配。默认工作区明确从 64 KiB 增至 1 MiB，工作单位上限从 32M 增至 64M；配置字段协议保持 v1，旧 v7 配置中的较小限额继续保留并按其限额执行。工作单位是已记录的 FFT 蝶形上界、采样混频、折叠频点、符号或码字测试，不能当作准确 FLOP 或实时吞吐量。一次真实 7575 假设作业实际计量约 47.46M，原 32M 限额正确拒绝，没有绕过预算。

独立合成 I/Q、频偏、共轭、短读、有限时钟漂移及共享校准追溯已经过验证；公开 SF12 向量通过实际参数编辑、串行后台、字节显示及 v7 保存重开。对一份 10 MS/s 的真实调查切片另以文件按需 FIR 提取到 1 MS/s，恢复 SF11/BW500k 的 50 字节、头与载荷观测距离为零的候选，未携带 PHY CRC。独立离线核对确认其外层 CRC16/成对编码/内层补和关系与调查候选一致。这是应用层提供者接入之前的首份切片证据；随后完整复现及范围见下节和实施记录，不构成设备归因。

## 成对编码 CRC16 经验应用帧族

`bounded-lora-paired-crc16` 是独立的恢复提供者，注册于 `plugins/research/recovery/registry.cpp`，复用提供者内部的 PHY 参数描述、有限解调与编码实现。成对编码规则、CRC 模型、候选优先级、修复、字段假设和语言资源均由它维护；通用界面、后台、配置和导出器没有增加实现 ID 分支。新增提供者没有将经验帧族混入 `bounded-lora-phy` 的校验含义。

配置明确给出偶数编码体长度（2–248 字节，默认 48）、01/10 极性、反射 CRC 工作初值（默认 0x0399）、最终异或（默认 0），随后接收两个大端 CRC 字节。多项式为正常形式 0x1021、反射实现形式 0x8408；成对解码采用 MSB 在前，要求全部内层字节总和模 256 为零。固定长度样本不能唯一识别初值、最终异或与固定前缀模型，不注册为已确认的厂商或业务协议。

应用有效候选在 PHY 内部的有限候选排序中优先保留，随后仍核对实际码字距离、截断、未知值及 PHY CRC。最多保留 32 个不同 PHY 内容，应用领域最佳集合因容量被截断时不能声称唯一。所选代表假设与原始 FFT、收到的码字、纠正码字、PHY 字节分别保留；应用选择、线上候选、内层字节和手动应用假设通过现有序列和依赖图表达。应用字节定位包含参考和参与选择的全帧约束，不能省略全局来源。

有限修复默认关闭。开启后只允许替换无效或未知的码对，不更改合法的已观测码对或接收 CRC。默认最多 12 个擦除码对（配置上限 16）、前 24 个排序输入（上限 32）、总共 131072 次赋值尝试（上限 1048576），最多保留 16 个不同解。CRC 差分与 Gray 顺序减少重复工作，但仍按总尝试、实际工作、工作区和结果预算限制并响应取消。保留原始码对、推得码对和修复位置；多解只将一致字节标为已知，保留集合不完整时不能导出确定内容。截断或接收 CRC 未知时不补造完整帧。

只有完整、唯一、没有应用修复、全部物理观测距离为零且 RMS/峰集中度资格门槛均启用时，才能将声明范围内的应用关系标为已验证。修复、物理错误、未知或禁用任一观测门槛均保持候选；不能因应用 CRC 一致而擦去 PHY 失败。任一已观测的必要关系失败时为无效，截断另列。PHY 未携带载荷 CRC 仍显示未携带；应用层通过不冒充 PHY CRC 通过或设备身份确认。

四字节前缀之后的手动 XOR、去除末尾补和的应用字节及可选 19 字节状态布局均为显式假设。状态布局只接受 48 字节编码体的整套配置：六字节值保持不透明，单字节序号、LE24 分钟、BE16 秒与未知单位字段不带厂商、MAC/OUI、业务或时间历元结论。参数及联动由提供者描述，保存的是已应用整套配置；缺失翻译按 key 回退。

独立发送侧码本/前向交织、连续相位 I/Q 与整体 GF(2) 长除法覆盖公开字节例、零距离关系、parity 错而内容不变、有限修复、CRC/补和失败、整套参数、资源、导出和大整数追溯。纯修复契约另构造满足双重约束的多解与保留上限反例。实际 Qt 工作流验证原始损坏字节和修复候选分开显示、候选导出、v7 保存重开及原生宽屏/缩放/紧凑窗口。

2026-11-12 已以生产提供者自行复现调查的 40 个事件：36 个严格结果、3 个弱候选、1 个未恢复；39 份内容与既有记录逐字节一致并通过独立 CRC/补和检查。弱信号采用另外保存的关闭集中度门槛配置，仍为候选；其中两份在本处理链中直接达到零码字距离，没有发生应用码对修复，不能照搬原脚本的修复过程。独立发送码本核对 4095 个头/载荷码字；真实数据、完整证据和配置留在忽略目录，详情及尚未完成的整体验收见实施记录。

## LoRa 符号编码与纠错

`plugins/research/recovery/lora/codec` 拥有 LoRa 符号映射、对角解交织、码字处理、头字段/校验、半字节拼接、去白化及 PHY 载荷 CRC。它只消费已经判决的符号，输出既有 `RecoveryData`；不导入检测器，也没有改动通用界面、后台、导出器或现有注册表。现已由下述 LoRa PHY 提供者接入 I/Q、有限时间/频率/漂移假设及通用桌面；独立应用帧族与完整调查复现见前节；编码契约本身不能替代真实录制验收。

编码参数包括 SF7–12、CR4/5–4/8、显式或隐式头、LDRO 及纠错策略；隐式头需要显式长度、码率和 CRC 参数。首块固定为八个符号、SF−2 个 CR4/8 码字，显式头占前五个半字节，其余数据继续进入载荷。后续块的列数为 SF 或 SF−2，不能把 SF7 显式头的首块错误计入载荷支撑。去白化使用初始 FF 的 x^8+x^6+x^5+x^4+1 序列，仅作用于载荷；PHY CRC 字节不去白化。保留头第四半字节的原始内容，只把其最低位计入已知的五位头校验。

纠错器穷举 16 个合法码字的已知位距离，只有唯一候选满足 2e+s<dmin 才在声明策略下执行有界纠错/擦除重建。CR4/5 与 CR4/6 不声称能纠正一个完整观测的错误位；检测模式保留系统位候选和失败状态。它不能证明实际错误数处于纠错半径之内，载荷仍需独立校验。已接收码字、已知位掩码、纠错后码字、半字节和字节分别进入序列，保留原判决和全部依赖；不能用纠正值覆盖原始错误。头与载荷的观测距离、纠正数量分别记录，不能用单个汇总数把弱候选混入严格结果。

未携带 PHY CRC 时保持候选；payload parity 失败但系统位与 CRC 一致时仍保留弱候选。显式头校验失败或参数不可知时不信任其长度/码率，阶段中保留失败证据。隐式头的检查为不适用，未计算的 CRC 不填虚假的零值。截断与可恢复擦除分开，收到的符号数不足时不把补齐槽位算作完整观测。空载荷没有字节范围时保留阶段/头证据，不虚构字节帧。

当前编码工作区包含实际 words/bytes capacity 及固定状态，仍可在 64 KiB 编码工作区和 8 MiB 结果预算内完成；输出、依赖、帧数、操作数及取消分别检查。I/Q 提供者按实际 FFT 与搜索空间在当前 1 MiB 默认工作区内另行计量，不能把编码层用量误称为整条解调链用量。若使用前导码或全帧约束选择同步/漂移假设，这些输入也必须进入可追溯依赖，不能只留下最终字节附近的局部符号。

核对依据为作者维护的 [LoRaPHY](https://github.com/jkadbear/LoRaPHY) 与其[公开实现及符号向量](https://github.com/jkadbear/LoRaPHY/blob/master/LoRaPHY.m)，不是调用其解码器得到测试真值。本仓库另写发送侧码本/交织与 GF(2) 长除法校验；公开 SF12/LDRO 向量恢复 01..09 和 CRC BA 2E，作为独立互操作锚点。测试还覆盖全部所列参数组合、短/最大载荷、错误与擦除、严格/候选/截断状态、大整数采样追溯及限额。编码契约未读取私有 RF 素材；当前 I/Q 提供者另有下述独立离线复验，两个验证范围分开。
