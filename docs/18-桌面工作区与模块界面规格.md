# 桌面工作区与模块界面

[English](18-desktop-workspaces.md) · 简体中文

## 职责

主窗口提供通用的接收机、会话、录制、事件与工作区宿主，不创建特定调制的高级设置。LoRa 的带宽、扩频因子等深入研究参数由 LoRa 研究提供者拥有、渲染、验证和保存，仅影响该研究任务。实时会话使用检测模块声明的默认搜索方案。不得把某种调制的参数当成整个软件的全局高级设置。

显示提供者创建带稳定标识与本地化标题的组件；工作区根据通用面板描述提供展示、隐藏、浮动、停靠、标签组合、分隔与尺寸调整。新增面板通过 `Workspace::add` 自动进入 View 菜单，不得在工作区或菜单中按提供者 ID 增加分支。研究参数通过 `ResearchProvider::controls` 与 `ResearchOptions::parameters` 传递，宿主不解析具体工具的字段。

## 实时研究面板协议

`LiveResearchProvider` v2 是随应用编译的 C++ 生命周期协议；v1 的监听订阅兼容行为保留，v2 增加独立接收租约和提供者摘要，细则见 [独立广播会话与状态栏规格](21-独立广播会话与状态栏规格.md)。组装位置为 `plugins/desktop/research/live_registry.cpp`。它与外部研究工具现有的快照 IPC 协议分别版本化，不能声称外部快照工具自动具有实时 I/Q 或原生界面能力。静态内置实现随应用更新，不伪装为可独立安装的 ABI 插件。

v3 在保留 v1/v2 语义及字段顺序的基础上增加同一提供者的额外面板描述、原生路径的录制输入和操作所需面板引用，见[波形实验室规格](22-波形实验室与可追溯分析实施规格.md)。额外面板不是额外的 I/Q 消费者；宿主使用明确的工具到主面板映射发布诊断、错误与操作。录制上下文的区间是文件相对样本位置，事件字段完整转交提供者。面板引用必须属于该提供者的已声明组件。关闭面板不停止任务，新增面板通过通用 View 和工作区放置/恢复机制接入；不按波形实验室、模型或检测器 ID 分支。新能力不得声明为 v2，也不改变外部快照 IPC 的能力。

v3 提供者可声明本地化的显式工作区预设标题。宿主通过通用布局描述和 `Workspace::addLayout` 自动登记到 View/Layout；应用预设前验证全部面板及引用，随后保留接收控制、状态和事件并放置提供者声明的主/附加面板。窄屏使用标签组合。仅用户选择该预设时执行，显示普通面板与窗口缩放不重新应用；保存恢复继续使用已有版本化布局状态，不根据研究工具 ID 重新推导用户布局。

提供者创建自己的组件、参数校验、偏好与语言资源，提供源上下文、非阻塞 I/Q 接收、事件操作、停止、忙碌状态和失败回调。除 I/Q 接收外的回调均在 UI 线程；I/Q 是借用视图，提供者必须在返回前复制需要保留的载荷，自行承担有界队列及处理线程。源上下文按会话代次发布，旧会话排队回调不得复活已经停止的工具。单个可选消费者异常只能使该消费者失效，不能阻断采集或其他工具。可选诊断快照为提供者拥有的 JSON，宿主只封装和导出，不按字段或实现 ID 分支。

实时 FM 的频点、收藏、搜台、输出设备、音量、静音、静噪门限、去加重及频偏归一化属于 FM 面板。事件菜单由该提供者声明，执行时打开其工作区面板。隐藏面板继续播放；停止音频只释放播放租约，停止监听只释放监听租约，显式断开接收机停止其全部实时使用者。独立播放的临时配置不覆盖已保存的宽带参数，手动参数入口及整套校验保留。当前版本输出单声道 FM 音频，不能把播放能力写成立体声、RDS 或所有信号都可解码。

信噪比显示为经过信道滤波后的恒包络估计，受干扰、衰落和削顶影响；静噪阈值不改变实际射频信噪比。播放状态必须区分缓冲、播放、恢复及失败；可恢复欠载不终止播放，真实错误应持久显示原因与诊断，不能只留下状态栏通用提示。缺少设备或整套待应用参数冲突时阻止开始，并给出可执行的修复入口。

音频设备、预缓冲和写入定时器运行于提供者独立的输出线程，不能依赖 GUI 定时器供给 PCM。界面只读取已发布的快照并传递控制，测试必须包括 UI 线程暂停处理事件时输出继续前进。频谱绘制按实际像素预算聚合，保留每列的峰值及噪声范围，不把不可分辨的 FFT 折线数量直接交给栅格描边。

## 布局持久行为

View 菜单集中管理面板显隐，提供监听布局、小屏布局、恢复默认布局、保存布局和锁定面板位置。每个面板标题栏支持拖动、关闭及双击浮动/停靠；用户可组合标签组和调节分隔条。关闭面板不会卸载其插件，隐藏与模块启停是不同操作；菜单和面板显隐状态必须同步。

大屏首次打开充分使用可用屏幕，默认同时展示频谱、瀑布、事件、状态、接收机控制及证据等信息。分析、录制、证据和各显示组件都是面板，不得因选择其中一个而强制隐藏其他组件。小屏可使用标签分组，接收机与开始/停止操作保持可访问。普通窗口缩放不得覆盖用户已调整的面板位置和显隐选择。

窗口几何、面板停靠/浮动、标签组合、尺寸、隐藏状态和布局锁保存到版本化的工作区偏好，下次启动恢复。显示器变化时，落在不可见屏幕的浮动面板重新停靠；损坏或不兼容的状态使用默认布局。恢复默认必须能够找回所有关闭的面板。

## 验收

有效的保存布局只恢复一次，不先运行默认布局，不在事件循环中重复恢复。默认布局的延迟尺寸调整只能作用于用户明确选择的预设。发布前必须使用已有的复杂分割/标签布局在真实桌面后端关闭并重启，不能仅以临时设置目录或 offscreen 测试代替。

隐藏窗口的停靠状态在普通窗口状态下恢复，随后恢复原有的最大化/全屏状态，仍只调用一次有效布局恢复。这样避免 Qt 6.8 在原生窗口管理器调整尺寸期间保留旧停靠项副本，导致立即选择新预设时访问已经删除的布局项。保存的几何、最大化状态和用户布局均须保留；不得通过清空用户偏好或延迟固定毫秒来掩盖重启故障。

通过独立新增面板验证无需修改 View 菜单；验证关闭/恢复、浮动、布局跨窗口保存与恢复、恢复默认。检查大屏同时展示多块信息与 640×480、1.25 倍缩放下的关键操作。验证 LoRa 专属参数只出现在所属研究模块，能传入算法并拒绝无效组合。原有监听、事件分析、回放和接收机设置回归必须通过。
