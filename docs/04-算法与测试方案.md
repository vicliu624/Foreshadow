# 算法与测试方案

[English](04-algorithms-and-testing.md) · 简体中文

验收结合独立数学真值、反例、提供者/资源扩展契约、运行测试、原生桌面和实际包。不能调用被测接收算法生成预期答案。

## 信号真值与解释

LoRa 覆盖未知时间/频率/BW/SF 与双极性。重复 Chirp 仅支持 CSS 候选；前导、同步、SFD 支持结构证据。PHY/应用校验属于后续独立证据。保留弱信号、边缘失败及周期 FSK 反例。

PSK 真值覆盖矩形、独立产生 RRC、定时/载波偏移、相位、时钟、多径和噪声。OFDM 使用显式逆 DFT/连续时间子载波，不复用接收合成。逐点核对有效载荷、独立信道频响及重算 EVM；已知数据参考不能改变同步/估计。

反例包括静默/噪声、CW、错误训练/模型、深陷波、缺样、截断、参数非法、取消和预算。未知及失败状态保留，不伪造数据。

## 测试族

| 领域 | 代表契约/检查 |
|---|---|
| 核心/编码/文件 | `core_contract`、`sample_codec_contract`、CLI 往返、来源/时钟/窗口/录制 |
| LoRa | 候选、paired-IQ、恢复 I/Q/codec、真实弱边缘和周期 FSK 负例 |
| 波形处理 | 处理、录制信道、波形/窗口分析、捕获、后台/保存工作器 |
| 模型 | reference model/builtin/digital/parameters 与原生流程 |
| 恢复 | `recovery_contract`、`coherent_recovery_contract`、原生恢复、独立字节/测量/复数提供者 |
| 架构 | 目标/头文件依赖、扩展契约、ID 路由、资源 key/占位符 |
| UI | 整套参数联动、工作区扩展、未知事件、语言回退、保存重开与定位 |
| 广播 | FM 连续/输出隔离、DTMB 原生接收/FEC、真实 codec 参考与媒体时序 |
| 分发 | 签名、兼容、路径、资源、事务、并发、激活及回滚 |
| 实际包 | `check_packaged_receivers.cmake`、`check_desktop_package.cmake`、Mac Mach-O 审计和实际安装 |

准确测试名使用 `ctest --test-dir build -N`；模块和平台条件会改变数量。

## 原生与发布包

覆盖宽屏、请求 1.25 倍及 640×480；检查实际可见数据、参数、错误、已知复数点点击、精确来源和布局重启。PNG 存在不等于通过；组件、主体启动和部署分别报告。

冻结源码，构建安装，归档解到中文/非 BMP 路径，发现真实模块，安装独立工具箱，重开示例、导出证据及核对运行库闭包。签名私钥不进入源码/构建任务。

## 实时证据

验证持续输入、短读、独立有界流、过载、全部选定阶段及 UI 暂停；分别报告提供/接受/拒收和实际预算。合成持续时长不是硬件连续性，短时零丢弃不能证明 24 小时无损。

`signal_capture_test --sustained-seconds 180` 为显式长测，普通 CTest 保持短时。实体工具手动调用，CTest 不打开硬件。Pager TX 收据仅证明芯片完成，不证明接收身份/载荷。

## 运行和报告

```sh
cmake --build build --parallel 4
ctest --test-dir build --output-on-failure
python tools/docs/check_docs.py
```

多配置增加 `-C Release`。保留首轮失败和修正依据，不以重跑抹除；记录通过、失败、跳过和外部阻断及源码/环境/输入。入口见[报告总览](README.zh-CN.md)与[当前需求](01-产品需求与验收.md)。
