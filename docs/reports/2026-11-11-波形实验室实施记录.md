## 已有实现

- `backend/iq/signal_window`：原生路径的录制范围读取、整数源时钟、分段样本、显式及隐式缺口、低层定位/选区、按规范化载荷和时间预算保留的预览缓存。正常保留过期与已知输入缺口分开统计。
- `backend/dsp/waveform`：统一的 I/Q、幅度、包裹/分段展开相位、相邻相位差、原始与因果移动平均瞬时频率。低幅度不隐藏原始 I/Q/幅度，不跨缺口或无效点求导/平滑。频率估计标在相邻区间右端样本，方法、阈值和参考频率保留在结果中。
- `plugins/desktop/research/waveform/trace_view`：通用轨迹消费组件，支持同步整数样本范围、A/B 光标、右键范围选择、滚轮/键盘缩放、采样点及按像素聚合。光标重绘复用缓存。未知轨迹 ID 可以直接显示。
- `waveform/laboratory` 与 `recorded_worker`：后台范围读取/取消、最新任务替换、不可变源重算、共享整数时间轴、样本读数及来源方法。配置保存实际已应用参数、源摘要、未知事件、选区和光标；大整数使用十进制字符串，重开时核对选中规范化窗口及元数据摘要，来源改变保留旧结果并拒绝替换。摘要范围不是整份录制文件。
- `waveform/plane_view`：消费任意一对共享样本轴轨迹，局部保留逐样本路径与缺口，宽视图用有界密度栅格。原始 I/Q 不标为同步后的星座；窗口与 A/B 和主轨迹一致。
- `backend/iq/signal_capture`：以实际载荷容量、块数及最大单块约束原始队列，try-lock 入队；后台统一解码、保留分段窗口并按 FIFO 冻结已接收前缀。冻结后继续输入不改变该窗口；代次隔离换源，拒绝、处理失败、停止清理、正常窗口过期及源缺口分开统计。保留缓存还限制片段数，极短分块的元数据有界。
- 通用研究布局：提供者声明资源标题及所属面板，`LiveTools::layouts` 转交工作区自动登记 View/Layout。显式应用前验证面板引用，保留接收控制/状态/事件；窄屏组合标签，不在缩放中重设布局。桌面不识别具体研究工具 ID 的行为。
- `waveform/capture_controls`：提供者维护目标中心、含保护带的通带及自动/手动策略，经既有接收租约请求推荐/整套评估/实际回读。独立于监听开始、跟随已完成快照、冻结后继续采集、停止并保留已接受前缀；读回及未知诊断完整显示。不同捕获使用 UUID，代次 token 拒绝同参数重连的迟到输入，旧代次计数不归入新源丢弃。组件销毁在控制线程关闭/回收原始窗口工作线程，之后的共享回调不会在采集线程等待该工作线程。
- 后台分析可接受无录制文件的不可变内存源；文件样本位置显示不可用，文件范围行隐藏。内存源可连同数据保存，成功重开后才显示真实存储样本位置。
- `backend/iq/signal_source`：输入容器提供者 v1，统一声明存储索引到源时钟的分段映射，原始编码与存储编码分离。保留原有 SigMF，增加版本化冻结容器；独立第三方容器在不修改窗口消费者的情况下读取真实样本。
- `waveform/analysis_save_worker`：后台持久化、取消、保存后实际回读和摘要校验；新建数据目录不覆盖已有文件，分析配置经 QSaveFile 原子提交。配置 v1 绝对引用仍兼容，v2 支持相对分析目录的 UTF-8 通用路径。捕获继续、跟随暂停，最多保留一个待分析快照；部分成功明确报告已验证数据副本与配置提交的不同状态。
