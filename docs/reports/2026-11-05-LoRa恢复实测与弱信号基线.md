## BW500/SF8 中心用例的离线复现

从上述三段正式界面录制中各只读提取 SFD 前 15000 对及后 12000 对 I/Q。以 112 对为步进扫描一个稀疏探测周期，每段 32 种起始位置。原始波形共 96/96 识别，未复现最初的实发漏检。

对同样的三段波形添加固定种子复高斯噪声，每档扫 8 种起点，比较加入双同步前后的 Windows 二进制。每个 I 或 Q 分量的附加噪声标准差为 0 至 28 个 CU8 数值时，每档两版均为 24/24。标准差为 32 时，两版均在同一段原始录制的六个相位漏检，其余 18/24 识别。此档每份未裁剪输入最多 7 个分量削顶。六个失败都没有进入精细对齐，其中四个也没有通过弱种子，另外两个通过弱种子后未生成精细对齐候选。

该实验隔离了已录制波形的输入起点及人工加噪，未保存首次现场漏检的原始 I/Q，不能追溯其原因。证据支持继续调查粗搜索的弱种子和下 Chirp 候选生成。原始截段哈希与逐项结果位于 `build/rf-tests/center-phase-sweep-20261105.json`、`center-phase-noise-ab-20261105.json` 和 `center-phase-noise-extended-20261105.json`。未更改目标机运行程序，后台观察仍在运行。

整符号上 Chirp 的峰值加入每模板 64 项有界缓存，供探测、前导码回填和弱种子复核共用。样本历史基准变化时清空缓存，需要完整 FFT 频谱的判据仍按原路径运行。Windows 同输入配对中，按事件内容比较，2 秒被动背景和 36 个实收／加噪片段拼入的忙碌录制结果一致。密集模式忙碌录制保留 34 个匹配，FFT 点数约 107.33 → 104.55 百万，减少 2.6%；被动背景约减少 0.5%。默认模式也通过结果对照。CTest 4/4 通过，报告为 `build/rf-tests/lora-up-window-cache-ab-20261106.json`。候选未部署。

## 窄带干扰配对回放

向 15 段实收 BW500/SF8 波形分别叠加连续单音与 1200 符号每秒的双频 FSK。干扰离信号中心 40–160 kHz，频点及相位由固定种子选择。目标 SIR 按已测匹配分量定为 0／−6／−12 dB，干扰在离线数字 I/Q 中加入。每个干扰另用不含发射包的实收背景生成反例。

| 干扰与目标 SIR | 默认模式 | 密集模式 |
| --- | ---: | ---: |
| 单音，0／−6／−12 dB | 15／15／14（每档 15） | 15／15／14（每档 15） |
| 双频 FSK，0／−6／−12 dB | 15／14／12（每档 15） | 15／14／12（每档 15） |

90 个仅含干扰输入在两个模式下均无结构误报。最强干扰档追加频域陷波对照。使用已知频率时，两种干扰下均恢复至 15/15。再用录制中已知在发射之前的短段估计至多两个主谱峰，未向估计器提供干扰频率，结果仍为 15/15，额外反例也无结构误报。该步骤使用已知安静时段，不能证明长时盲估计的可靠性。陷波实验未进入正式检测，避免影响同时出现的窄带信号和未知弱包。逐项数据为 `build/rf-tests/lora-narrowband-interference-ab-20261106.json`、`lora-narrowband-oracle-notch-20261106.json` 和 `lora-narrowband-estimated-notch-20261106.json`。

进一步改用整段时频谱的局部突出程度和跨帧占用识别至多两个持续谱线，无需输入已知的发包时间或干扰频率。加入离线联合扫描选项 `--lora-notch`，保留原始 LoRa 与其他分类结果，仅另列滤波后新增的结构匹配。−12 dB 干扰组单音由 14/15 提升到 15/15，FSK 由 12/15 提升到 15/15，30 个仅干扰对照无误报。原始 I/Q 不写回，正式监听未改变。验证文件为 `build/rf-tests/lora-blind-notch-integrated-20261106.json`、`lora-blind-notch-cli-20261106.json`。

陷波加入两端保护区，避免循环卷积把片尾的强载波串到片头。回归覆盖片尾强载波，实收加干扰正例的 15/15 结果保持。两段各 8 秒环境录制在当前门限下均无 LoRa，也未触发陷波。另在第一段全长加入 478.803 MHz 持续单音作为已知反例，八窗均检测并抑制该谱线（频率估计约 478.802990 MHz），原始和滤波结果均无 LoRa 事件。报告为 `build/rf-tests/passive-notch-20261106.json` 和 `passive-notch-forced-carrier-20261106.jsonl`。

## 同次采集的原始对照录制

新增有限诊断选项 `monitor --audit-iq-output`。单次数据同时进入现有分析与录制队列；原始对照由写盘线程保存，样本必须连续，事件录制照常独立判定。上限为 8 秒和 32 MiB，输出须为新目录并与事件库分开，默认长期监听不写连续 I/Q。程序结束后诊断目录包含 SigMF 及原始样本计数、完成状态和采集结果。

例如在能独占 SDR 的测试窗口运行 `signalscope monitor --seconds 8 --rate 1750000 --frequency 478500000 --gain 38.6 --threshold-db 11 --output events --audit-iq-output raw-audit`。可随后用 `signalscope detect --input raw-audit/capture.sigmf-meta` 比较实时与离线结果。Windows 回归验证无事件时仍保留逐字节一致的对照、拒绝覆盖、拒绝与事件目录嵌套、拒绝无限与超时长配置。CTest 4/4 通过。ARM 候选正在编译，正式接收未切换。

Windows 原速重放一份 8 秒背景与已知弱包的组合输入。默认分析没有事件，原始对照保存全部 14000000 对 I/Q 且与输入逐字节一致。随后从该文件重检，默认模式仍为零，密集模式找回一帧并通过参数与 SFD 起点核对。报告为 `build/rf-tests/audit-iq-recovery-20261106/report.json`。

Pager 诊断工具 `tools/rf_diagnostic_capture.py` 增加 `--monitor-exe`，可在有限实发窗口同时保留原始对照、实时检测状态和串口发射回执。结束后按原频率、增益、采样率、线程及门限恢复接收。模拟验证通过，尚未占用硬件进行该模式实测。

ARM 构建完成后用与 Windows SHA-256 相同的 8 秒输入复核。默认分析零事件，原始对照完整保存 14000000 对 I/Q，逐字节一致。重检对照时默认零匹配，密集模式找回一个 BW500/SF8，SFD 起点通过核对。重放前后正式监听的丢弃和缺口计数均无增量。结果为 `build/rf-tests/lora-audit-replay-arm-20261106.json`。此项为重放路径验收，原始对照与 Pager 同次空口采集仍待测试。

新增 `tools/compare_lora_audit.py`，用 `--input`、`--live-status`、`--exe` 和 `--output` 对现有诊断记录生成实时、默认离线、密集离线三方报告。核对完整性、采样数、采样率和中心频率，并沿用实时带宽、SF、极性、时间相位和门限。按 SFD 起点和中心频率做一对一匹配，分别保留缺失、新增和歧义，不据此确认载荷。Pager 工具加 `--replay-exe` 可在采集完并恢复正式程序后自动生成 `comparison.json`。已验证 14000000 对弱包重放的 0／0／1 结果及一段真实边缘包在三路的 1／1／1 匹配。

## 两个实收包的重叠对照

将两段独立接收的 BW500/SF7 Pager 波形在数字域移频和重叠，设置中心间距 0／125／250／650 kHz，每档三种时差及三种相对幅度。默认和密集宽带分支的统计一致。间距 650 kHz 时两信号的标称带宽不重叠，但原宽带分析九组中只有一组检出两包，其余各检出一包。间距更小的试验仍可能漏检或出现额外结构输出，不能据此证明支持同频碰撞分离。

离线联合扫描增加 `--lora-split`。原始识别保留，另在采集中心两侧的固定子窗独立重检，按参数、SFD 和频率去重，新增结果放入 `lora_split_events`。1.75 MS/s 下子窗中心偏移为 ±350 kHz，中心搜索各 200 kHz。650 kHz 间距的九组重叠样本中，联合结果均检出两包且无额外匹配。该选项增加离线处理开销，覆盖固定子窗内的分频带情况。报告为 `build/rf-tests/lora-collision-replay-20261106.json` 和 `lora-collision-split-cli-20261106.json`。

扩展对照改用仓库中另一对实收边缘波形。四种非重叠频率组合下，等强的 12 组中原宽带均无匹配，分带后六组检出两包、六组检出一包。相差 ±9 dB 的 24 组中仍各仅检出一包。对称频点的单独重放在相同幅度下两包均可检出，未据此归因于单包本身。增加子带数字增益未改善；收窄滤波过渡带反而丢掉部分已有匹配，两项撤回。实收对称等强的三种相对时差加入 `subghz_split_lora` 自动回归，核对两包的中心、BW/SF、极性和 SFD，要求恰好各报一次。明细为 `build/rf-tests/lora-collision-diverse-20261106.json` 及 `lora-collision-equal-before-taper-20261106.json`。

为区分分带能力与离线合成时放大两份宽带背景的影响，在保持同样频点、时差及 ±9 dB 的条件下，先将两段实收 I/Q 分别限制在各自 560 kHz 信道，再合并到同一份接收背景。24 组中宽带每组一包，分频带后每组两包，无额外事件。这个结果证明当前方案可分离这批频带隔离的强弱包；未带限输入的漏检仍保留，实际噪声和串扰环境未通过此对照验收。Windows 和 Linux 回归新增两组不对称频点的带限强弱例。报告为 `build/rf-tests/lora-collision-bandlimited-20261106.json`。
