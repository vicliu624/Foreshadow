Foreshadow **0.2.12 r4** 已提供分别组装的基础程序与可选 SDRplay 服务客户端。
运行时／源码／许可材料冻结于 `f763a3053db6e9edca4be23e50fb6c67ae42fab5`。
后续文档提交记录这一冻结版本，不改变已验收的二进制。两平台评审版已部署，默认英文界面。
[机器证据](2026-11-14-receiver-service-proof.json)包含归档哈希、命令结果、源码重建、

## 选型与实现

先按现有采集／控制契约评估 SDRconnect。公开 WebSocket 1.0.3 协议未建立完整的 IF 增益衰减、
硬件 AGC、硬件 IF 滤波及高级设置对等能力。接收机工作站未安装 SDRconnect，获取官方安装脚本
返回 HTTP 403；未执行安装器或自动接受厂商条款。这是公开协议评估与原生验证的外部阻断，
不是声称原生试用失败。[服务指南](../receiver-services.zh-CN.md)提供官方规格链接、
能力对照及安装说明。

后备选用未修改的上游 **SoapyRemote 0.5.4**，修订
`bd10a2e4a916bf66f0faa36dca7f043d4268138c`，BSL-1.0。
程序／客户端不分发厂商 API、本地 SoapySDRPlay3 驱动或服务端可执行文件。
客户端只调用 remote 注册函数，不调用 SoapySDR 全局工厂或加载本地硬件模块；
已移除原 Windows 厂商 DLL 预加载路径。接收机电脑独立安装上游服务，使用用户原有的驱动／API。
没有声称取得新的厂商或固件授权。

| 变化轴 | 所有者及组装位置 | 稳定消费者 |
|---|---|---|
| 服务地址、硬件规则及回读 | SDRplay 接收机提供者、其资源及接收机 CMake 组装 | 通用设置界面、CLI、共享接收会话 |
| 发现前的连接设置 | 接收机请求协议 2；C ABI 仍为 1，保留旧请求行为 | 通用描述与设置透传；拒绝不支持的协议 |
| 可选应用内容 | 提供者声明的 `bundle_with_application`、资源／运行库归属 | 通用组包器、安装器及签名器 |
| 对应源码与声明 | 各包根及经过评审的平台配置 | 通用收集器、归档检查及许可证视图 |

宿主没有新增厂商 ID 路由。原 ID、设置根、命令名及录制元数据保持兼容。
独立提供者／资源测试验证扩展不改变宿主二进制。客户端要求宿主 0.2.12；
使用新服务部署前应更新旧的受管直连接收机工具箱。

连接地址在设备发现前编辑，刷新／探测／应用传递同一份保存设置；改地址后旧探测失效。
原天线、采样率、增益、滤波及高级控制继续属于提供者。TCP 原生 CS16 流使用有界帧与按速率
计算的 socket 预算。客户端读取统计与未知的服务端驱动／硬件丢样计数明确区分。
溢出、异常结束、取消和服务死亡保留已接受前缀，并返回明确结果。

检查现直接计数 Windows DLL 目录条目；Unix 仍按真实路径对符号链接去重。
保留原 Unicode 目录及完整流程，没有关闭保护或放宽包检查。
没有把较早完整 CTest 重标成最终冻结版本的运行；最终解包流程与源码重建均在该冻结版本执行。

原生契约使用真实上游服务与独立模拟硬件提供者，覆盖持续定速输入、短读、溢出、启动失败、

自动加载硬件模块。还覆盖带连接设置的独立提供者、旧回调、未来／小数／缺字段协议元数据、
中英文界面、已保存地址优先级及资源回退。原有 PSK／OFDM、PCM、FM、电视、持久化和工作区
回归仍在发布包验收中。

源码重建从实际交付的生产源码归档与固定依赖源码材料开始，重建第一方程序、提供者／辅助工具
及 SoapyRemote 客户端，复用精确的既有 Qt／原生 SDK，不代表全部依赖重新构建。
QtCore 替换用带无行为尾部的兼容 DLL／ELF 副本并验证加载路径；证明替换／加载入口可用，

## 实体服务与界面

连接接收机的 Debian 13 工作站运行用户级 `foreshadow-receiver.service`，显式绑定可信局域网
接口。独立构建的上游服务位于 `/home/vicliu/Applications/SoapyRemote-0.5.4-bd10a2e4`，
保留原始源码、BSL 条款和构建说明。进程映射显示 API 与硬件驱动只在该服务加载，最终包的
Windows/Linux Foreshadow 采集进程均未加载它们。服务实测硬件模块集合为 MIT SDRplay 驱动，
未观察到其他硬件模块。

设备为 RSPdx-R2。开发原生构建另完成两客户端 2 MS/s、30 秒及 Linux 10 MS/s、10 秒采集。
这些是有限窗口的接受样本观测，不能证明长期硬件连续性、硬件丢样计数、所有设置／信号或
多个客户端同时拥有硬件。
