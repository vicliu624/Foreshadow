# 在线更新与受控工具箱发布验收

[English](2026-11-09-toolbox-distribution.md) · 简体中文

## 范围与扩展边界

本次实现官方目录下的软件更新及工具箱分发，不包含拖拽连线、任意源、账号市场或第三方自助上传。工具箱中心提供官方目录、已安装、可用更新和软件更新页面，支持安装、更新、启停、卸载、回退、离线导入、缓存清理、启动检查和手动检查。内置分析模块如实标记为随应用发布。

目录协议、网络传输、通用安装事务、包类型、运行时组件发现与应用激活分别拥有其规则。独立提供者、第三个接收机模块、资源增量和测试包类型验证扩展不依赖具体 ID 分支。界面、CLI 与会话均不引入具体接收机或研究工具的规则。工程要求落在 AGENTS.md 及规格 16、17、18。

固定官方入口为 `https://github.com/vicliu624/AMC/releases/latest/download/catalog.json`。目录使用 Ed25519 签名，包按精确 SHA-256、展开大小、平台、版本、依赖及组件验证。安装提交采用锁、暂存目录和原子状态；当前及恢复版本、进程租约约束延迟清理。启动助手等待旧进程退出，校验新进程凭据和存活状态，失败恢复入口和安装状态。设置、原始录制不属于应用安装目录。
