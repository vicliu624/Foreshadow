# 宽带接收与多速率分析

[English](14-wideband-and-multirate-analysis.md) · 简体中文

本次改造以 RSPdx-R2 和 uConsole AIO V2 的实际硬件、驱动能力为配置依据，取消沿用自 RTL-SDR 的全局 3.2 MS/s 监测限制和固定 1 MHz 推荐搜索范围。采集采样率、接收频谱范围、IF 滤波器的标称 3 dB 带宽、各检测器内部处理采样率分别建模。

## 必须满足的行为

1. RSP 允许使用驱动支持的宽带采样率，包括 10 MS/s；AIO V2 按实际 RTL 调谐器、驱动及输入模式评估，不将 RSP 参数套用于 RTL，也不把 RTL 的限制套用于 RSP。
2. 搜索范围可覆盖所请求的接收频谱。IF 标称 3 dB 带宽和检测器边缘余量用于说明有效覆盖和衰减风险，不再使整个监测窗口被固定压缩到约 1 MHz。真正超出采样频带或硬件能力的请求仍明确拒绝。
3. 宽带 I/Q 独立进入原始录制与频谱路径；LoRa、窄带检测和快照检测使用适当的分信道/变采样率路径，不能因降低内部分析采样率而只分析中心频段。
4. 分信道必须抗混叠、保持流式相位和历史，正确处理非整数速率比、输入缺口及末尾块。事件的频率、原始采样索引和录制位置须准确映射回宽带源。
5. 2.048、2.4、2.56、3.2 MS/s 等硬件允许的采样率，不再因 LoRa 的整数符号样本要求被拒绝；由内部速率转换解决。
6. 公开实际分析覆盖、队列积压、跳过/丢弃和负载；吞吐不足时明确标示降级，不能静默缩小搜索范围、捏造无丢失状态或关闭用户选择的检测器。
7. 推荐配置按设备能力和用途给出，完整硬件范围可以选择；主窗口、设置页、调制评估、CLI、实机回读采用一致的规则。
8. 两台接收机分别完成能力与设置验证、数据采集、宽带检测覆盖与性能评估。源码和打包回归通过后部署至 uConsole，替换旧实现。

## 处理结构

采集线程保持原始 I/Q、采样率及中心频率，原始录制与有限速率的频谱显示独立运行。分析线程使用共享 FFT 的多通道频移/低通/抽取器，必要时再进行分数速率转换，将各频道交给内部采样率合适的检测器。频道间保留重叠，过滤重复事件；捕获外缘无法完整容纳的信号应在覆盖信息中说明。

LoRa 分信道共用有界工作线程池，避免每个频道再创建多个线程。窄带与快照分析保留原始频率和时间映射；FM 音频和高采样率录制回放也必须通过对应路径验证。

LoRa 使用所选最大 BW 的四倍作为内部分析时钟，频道重叠覆盖可完整容纳信号的中心频率范围；兼容的低采样率窄幅请求保留直接分析路径。高采样率 FSK/OOK/ASK/FM 使用 2 MS/s 分信道；低采样率保持原始时钟，并将输入对齐到 256 点 FFT 步进，避免短 USB 读取、任意分块或分数时钟破坏幅度历史。FM 音频先抽取到 400 kS/s，再执行导频之外的音频解调。高采样率 PSK/4-FSK 快照的候选信道用 80 kS/s 抽取，CSS 与 OFDM 保留完整原始频谱。

分信道器采用共享前向 FFT、低通滤波与频域抽取，随后按需执行分数速率转换；FFTW 不可用时使用 KissFFT。`SIGNALSCOPE_FFTW=OFF` 可显式验证回退实现。FFTW 的规划与销毁在所有调制及 DSP 模块间串行保护，执行仍可并行。LoRa 分信道直接交付浮点样本，避免中间反复量化为 CI16；原始录制格式不受影响。

频道间距按最大 LoRa BW 规划，最外侧频道同时覆盖最小所选 BW 能完整容纳的位置，避免选择多 BW 时人为丢掉外侧的小带宽信号。FFT 移频还显式裁掉原始 RF 频谱以外的循环索引，不能把另一端频率绕入当前频道。结构检测在粗候选落到第二个 SFD 下扫符号时，用同一组前导码、同步、双下扫、四分之一结尾及转换条件复核前一个符号；不降低匹配阈值。

“推荐宽度”和“使用推荐配置”会选择“当前最大可用”模式，因此随后改变采样率时宽度随之联动。自定义与固定预设仍保留用户请求，超过采样范围时显式冲突。IF 3 dB 宽度、ADC 位数、I/Q 格式及实际分析信道数在设置页直接可见；负载、分析丢弃、旁路跳过和快照繁忙计数在运行状态公开。

## 验证证据

验证应覆盖宽频谱两端与频道交界的已知合成信号、带外混叠抑制、任意块分割、缺口重置、分数速率及时频映射。原始录制字节数和索引独立检查。硬件实测记录每台设备的 USB/驱动身份、应用值、吞吐、CPU、队列和实际分析覆盖，区分静态能力、短时测试与长时间运行结论。

AIO V2 的制造商资料描述了独立 SDR 电源控制及 HF 直接采样；实际枚举和驱动能力须先确认。参考：[制造商产品页](https://hackergadgets.com/products/uconsole-aio-v2)、[制造商设置说明](https://hackergadgets.com/pages/hackergadgets-uconsole-rtl-sdr-lora-gps-rtc-usb-hub-all-in-one-extension-board-setup-guide)。RSP 参考：[RSPdx-R2 规格书](https://sdrplay.com/wp-content/uploads/2026/06/RSPdxR2_Datasheet.pdf)。
