# v4 弱信号研究快照

[English](README.md) · 简体中文

这里保存了主源码合并已验证 v3.1 检测器前的完整 v4 源码快照。弱前导码、同步联合证据和共同观察区间模型的工作没有删除，也不计为已交付或已解决。

`source-before-buffering.tar` 包含当时的 CMakeLists.txt、include、src、tests 和 tools；SHA256 见 `snapshot.json`。它不包含构建目录、依赖源码或私钥。可解压到一个新的独立目录后配置构建，不要覆盖已安装接收器。

该快照使用 0.5% 转换模型优势，完整回归失败于弱噪声到达偏移 0.67。另一个隔离构建 `build/v4-margin-source` 以 0.1% 优势通过了本机四项测试，但独立 800 样本比较发现两种优势均误判同一个错误 SFD 种子 914001。比较计划和结果保存在 `build/rf-tests/v4-margin-holdout-*.json`。这只是候选评估，尚未在 ARM 或实际射频中验收，不能据此称为可部署版本。

当前主源码以已通过 ARM 原生测试及真实收发复核的 v3.1 检测器为基础，继续修复有界缓冲和录制完整性。识别弱信号的研究仍是未完成工作，实验失败、误判和限制保留在诊断报告中。
